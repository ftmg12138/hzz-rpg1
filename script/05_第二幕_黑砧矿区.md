# 05 第二幕：黑砧矿区——山腹里的第四个声音

> 预计游玩 18—26 分钟。本区现为可选的高风险治疗调查：能取得稳定材料、照心骨和大量真相，也可以只救矿工后返回雾钟城。四条入口在矿工营地汇合，但不会强迫玩家从矿井直接进入终幕。

## A2-MINE-01A 帝国检查站

〔进入〕选择帝国路线。

【旁白】检查站用两辆横过路面的货车拼成，车板后架着重弩。帝国旗被矿尘染成灰色。哈兰不在，代理军士名叫维斯，眼神已经被连续两夜的值守磨平。

他要搜身、登记同伴，并暂扣“来源不明的古物”。玩家的残片容器在听见这句话时同时发热。

### 选择

1. **出示哈兰文书，允许搜普通装备但拒绝交残片。**
   - 有正式文书自动通过；无文书 CHA DC 16。
   - 通过后获得一条警告：帝国工兵已把炸药埋在旧井支柱，黎明引爆。

2. **把残片伪装成普通私人物品。**
   - DEX/CHA DC 13；同伴莉瑞尔在场有优势。
   - 失败时维斯摸到容器，短暂看见自己的儿子，随即恐慌鸣哨。`alarm_mine +1`，仍可冲入营地或让汤姆担保。

3. **用托伦犯罪证据换免检。**
   - 交出账册、假印或俘虏口供。`rel.harlan +1`，证据从背包移除；帝国答应延后半小时爆破，但派两名兵跟随。

4. **煽动士兵拒绝炸矿。** 〔有艾琳记录、父亲军信或高 CHA〕
   - CHA DC 16。成功三名士兵卸下引信，`evacuation_delay = true; rel.harlan -1`；失败维斯下令拘押，玩家从押送途中进入营地，双手暂被束缚。

5. **攻击检查站。**
   - 一场困难战斗。胜利可拆除地表引信并取得军用绳索；失败不会立即死亡，玩家被关入矿区囚牢，转 `A2-MINE-04`，HP 至少保留 1。

→ `A2-MINE-02`

## A2-MINE-01B 托伦商道

〔进入〕选择托伦路线。

【旁白】商道比官道平整，因为托伦的人知道货车比农民更会赚钱。每隔百步便有一盏装在铁笼里的油灯。灯下挂着欠债人的木牌，姓名被雨泡得发胀。

矿区门楼敞开。疤脸托伦本人坐在一张铺熊皮的椅子上等你。他四十岁上下，左脸的伤从太阳穴拖到嘴角，使笑容永远只抬起一边。

【托伦】“能走这条路的人，要么是朋友，要么还不知道自己已经答应做朋友。”

他想要玩家的残片容器，或至少要玩家带它下井，让第四残片“醒透”。交换条件按主角变化：

- 艾德里克：三人离境文书、四十张票据、父亲处决名单。
- 莉瑞尔：苔冠行动完整档案与副尉科尔现址。
- 索林：合法交货印、家族五年矿具订单、科德自由。

### 选择

1. **接受交易，但只答应带路不交残片。**
   - `toren_bargain = true; rel.toren +1`。他给矿区自由通行与一名护卫“钩鼻”哈克。

2. **要求先兑现私人目标。**
   - CHA DC 13。成功取得可验证的一半：文书、档案两页或盖印；`private_goal_secured = true`，但托伦留有撤销手段。
   - 失败他只允许你亲眼看见目标物，关系不变。

3. **假意答应，计划下井后反悔。**
   - CHA DC 13；成功 `toren_bargain = true; betrayed_toren_pending = true`。
   - 失败托伦仍放行，却派两名护卫并拿走你一件存仓物作为抵押。

4. **公开拒绝。**
   - 若有矿工、帝国或赫尔嘉支持，可安全退到侧路；否则托伦叫人缴械。
   - 选择投降转囚牢；选择战斗提高 `alarm_mine 2` 并从营地外缘继续。

5. **问他为什么不开采第四层。**
   - INS DC 13。成功看出他真正害怕下井：“第一次钻开石门时，二十三个人开始互相喊死去亲人的名字。托伦亲手封门，却从那晚起梦见一顶没有头的王冠。”`toren_dream = true; truth +1`

→ `A2-MINE-02`

## A2-MINE-01C 旧排水渠

〔进入〕选择排水渠路线。

【旁白】排水渠只在地图上像一条线。实际钻进去时，它是齐膝的黑水、贴着头皮的石顶和无数不肯让路的木撑。米拉在入口系过红布，每隔三个岔口一条；第五条红布被人割走，只剩湿结。

前方传来孩子般的哼唱。水面漂过一只矿灯，灯里没有火，只有白色微光。

### 选择

1. **跟红布走，不理会歌声。**
   - INS DC 13；有路线图自动成功。成功抵达营地储水池，未被发现。失败绕进塌方区，失去一格时间并触发 `R-TRAVEL-04`。

2. **跟随发白的矿灯。**
   - 它引向一名被困在栅栏后的少年矿工皮普。救他需 STR DC 13或工具；成功 `mercy +1; miners_contact = pip`，并得知囚牢换岗口令。
   - 若不救，灯会继续向深层漂去，`fragment_pressure +1`。

3. **检查被割走的红布。**
   - 发现托伦护卫设的细铃与新脚印。可拆除（DEX DC 13）或反向布置。
   - 成功 `alarm_mine -1`；失败铃响，抵达营地时已有伏兵。

4. **让残片选择方向。**
   - 自动抵达最短路径，并看到第四残片所在的垂直方位；`fragment_used +1; resonance +1`。
   - 每位主角看见不同幻象：父亲在水下走路、许多手从暗处伸来、石壁像胸腔一样收缩。

→ `A2-MINE-02`；隐蔽成功时 `mine_entry_hidden = true`。

## A2-MINE-01D 山脊猎道

〔进入〕选择猎道路线。

【旁白】凯尔所谓的路，是山羊偶尔愿意踩的几块石头。矿区火把在下方排成弯曲的蛇。越过山脊能直接到旧升降井上层，却看不见囚牢与工棚。

半路有一名帝国斥候倒在岩隙，腿被捕兽夹咬穿。他看见凯尔的精灵箭羽便去摸刀。

### 选择

1. **救斥候并说明来意。**
   - 消耗医药或 INS DC 13。成功 `mercy +1; imperial_scout_saved = true`，得到爆破引信位置。

2. **只拿他的地图。**
   - 他仍活着，会记住你。取得 `mine_upper_map`，`rel.harlan -1`。

3. **结束他的痛苦。**
   - 若先问同意，他请求你把徽章寄给儿子：`mercy` 不变，获得徽章。
   - 不问便杀：`cruelty +1; rel.kael -1`。

4. **绕开。**
   - 不耗时，无倾向变化。他可能在帝国引爆前获救，也可能没有；由 `evacuation_delay` 决定。

抵达崖顶时需要 DEX DC 13跨过断栈桥；失败由同伴救住，关系 +1但丢失一件最外层轻物品。独行失败则失去 4 HP，仍爬上平台。

→ `A2-MINE-05`，跳过营地初访；囚犯未救且托伦先取得玩家到来消息。

## A2-MINE-02 黑砧营地

【旁白】黑砧不是一个矿洞，而是一座围着井口生长的木城。工棚、宿舍、熔炉和账房层层叠叠，最中央的升降架像一副竖起来的巨大肋骨。今夜它停着。四十多名矿工挤在绞盘前，托伦的护卫守着另一侧，谁都不肯先动。

老矿工奥斯温站在人群最前。他是布兰的儿子，实际已三十多岁。脸上的白矿尘被汗冲出两道沟。

【奥斯温】“下面还有十七个人。主轴裂了，他们不让我们拿新甲扣修，说第四层的东西必须先运上来。”

托伦方的监工哈克则说，下面的人已经“发疯”，贸然升笼会把病带上来。

### 第一态度

- 有布兰工牌、警告或救过皮普：矿工相信玩家，`rel.miners +1`。
- 带托伦护卫或木牌：护卫让路，矿工不信任。
- 带帝国士兵：双方紧张，任何失败使 `alarm_mine +1`。
- 隐蔽进入：可以先偷听，再选择现身位置。

### 公开处理

1. **先修升降架。**
   - 需要 `reinforced_lift_parts`、甲扣箱或现场拆料。
   - 工匠检定 DC 13；索林或其同行自动有优势。成功 `lift_repaired = true; workers_warned = true; rel.miners +2`。
   - 失败发现主轴被人故意锯过；仍可临时修，但必须有人留在绞盘旁手动制动。

2. **先下井确认发疯原因。**
   - 矿工认为你偏向托伦，关系 -1；获得快速下降权，但若无后援，受困者会在共鸣上升后死伤。

3. **煽动矿工冲破护卫。**
   - CHA DC 13；成功控制营地但 1 名矿工受伤，`alarm_mine +2; rel.miners +1`。
   - 失败演变为混战，玩家必须选择保护哪一方；无论如何耗时一格。

4. **说服双方同时派代表下井。**
   - 需要关系证据或 CHA DC 16。成功奥斯温与一名护卫同行，营地暂时停战；失败监工要求玩家先见托伦。

5. **展示残片容器。**
   - 所有人短暂听见各自最强烈的情绪。矿工跪倒，护卫后退。你获得控制场面的优势，但 `fragment_used +1; corruption +1; resonance +1`。

→ 玩家选择 `A2-MINE-03`（工棚/账房）或 `A2-MINE-04`（囚牢）；每处耗半格，通常只能完整处理一处再下井。

## A2-MINE-03 工棚与断轴

【旁白】工棚里摆着拆下的旧主轴。切口平整，不像磨损。旁边有三具用布盖着的尸体，手指都因抓挠石头磨到见骨。墙上用煤写满同一句话：“我看见你看见我。”

账房柜里有四类资源，玩家可在耗时前取两项；强行全拿会触发守卫或坍塌。

1. **升降架维修册。** 降低维修 DC，记录托伦明知主轴被锯仍阻止更换。
2. **第四层工人名单。** 可在井下逐个呼名唤醒迷失者，`workers_list = true`。
3. **炸药与引线。** 2 格；可毁门、断追兵或用于终幕摧毁方案，但会增加坍塌风险。
4. **铅衬工具盒。** 1 格；可短暂容纳第四残片，降低携带者压力。

### 检查尸体

INS DC 13：死者没有互相攻击伤，而是同时向同一面石墙挖掘。墙后有一条被封的旧通风道，通往囚牢下层。成功 `truth +1; prison_hidden_exit = true`；失败触摸尸体时触发主角专属侵扰。

### 索林专属

怀表靠近断轴时逆向作响。他能看出主轴不是托伦的人锯断，而是从金属内部被一种共振震裂。托伦只是利用了事故。公开这个事实会降低矿工对托伦“蓄意杀人”的确信，却证明共鸣正在扩散。

→ `A2-MINE-05` 或先去 `A2-MINE-04` 并 `time +1`。

## A2-MINE-04 木栅囚牢

【旁白】囚牢原本是存爆破粉的石屋，只有一扇小窗。里面关着九个人：罢工矿工、科德、被仓库带走的人，以及一名穿帝国旧制服的老人。

老人自称科尔，正是十年前苔冠行动的副尉。他没有逃到海外，而是在替托伦辨认残片后被扣住。莉瑞尔在场时，他认出她的眼睛。

### 开门方式

- 托伦钥匙或护卫身份：直接开。
- 撬锁：DEX DC 13；失败响铃，仍能砸锁但警戒 +1。
- 炸药：必开，囚犯各受 1—3 点伤害并可能引发上层坍塌。
- 从通风道：有线索时直接进入，能先听口供再决定是否放人。

### 囚犯选择

1. **释放全部。**
   - `miners_freed = true; mercy +1; alarm_mine +2`。需要一名同伴带他们撤离，否则移动缓慢。

2. **只放能战斗的人。**
   - 获得两名临时援手；留下伤员，`rel.eilyn -1`（若知情），`rel.miners` 不变。

3. **以协助为条件放人。**
   - 矿工同意守绞盘；科德愿意作证；科尔只答应带路。无腐化，但若玩家明知撤离危险仍强迫，`cruelty +1`。

4. **把科尔交给凯尔/莉瑞尔处置。**
   - 凯尔想杀他；莉瑞尔可阻止、允许或亲自动手。
   - **要求公开审判。** CHA/WIL DC 13；成功科尔活到结局并提供完整口供，`private_goal_secured = true`。
   - **允许复仇。** 科尔死亡，得到他衣内命令原件；`cruelty +1`，凯尔关系 +1或莉瑞尔碎片压力降低。
   - **亲自杀。** 无检定。莉瑞尔路线 `corruption +1`，账页真相仍完整但失去活证人。

5. **审问科尔后把所有人继续关着。**
   - 获得路线和口供，`cruelty +1`。若爆破发生，他们的生死写入结局。

### 科尔的口供

他承认塞维兰顾问办公室下令取回“饥渴”容器。赛拉最初合作，因为帝国承诺撤走驻军并保护混血孩子；她发现被带走的持有者都变成空壳后反悔。袭击当夜，科尔允许部下点火逼她交出银链。所谓兽人尸体是事后运来的伪证。

【科尔】“我不是被法术控制。我只是相信命令会替我承担后果。后来才知道，命令从来不记得我们的名字。”

这段口供提升 `truth` 至少到 2，并完成莉瑞尔的事实调查，但如何处理事实仍由结局决定。

→ `A2-MINE-05`

## A2-MINE-05 旧升降井

【旁白】旧井像一张竖直的黑口。升降笼悬在中央，铁索上不断落下白灰。往下望时看不见底，只能看见每隔几十尺嵌在井壁的古代铜环。

绞盘旁有两个位置：操纵杆与紧急制动。若主轴只是临时修复，必须有人留下控制；这意味着该人无法继续进入深层见证室，并在帝国爆破时承担风险。

### 谁留下

- 奥斯温自愿留下，前提是救过矿工或布兰未被伤害。
- 索林同伴可留下并保证装置；他之后仍可能从地表前往雾钟城，但不会参与本次深层调查。
- 格罗姆若同行会留下，说“有些门我年轻时打开，现在该学会守住”。
- 命令低关系 NPC 留下需要威胁，会记录 `forced_brakekeeper = true`。
- 无人留下：升降笼在途中发生制动危机。

### 下降

半途，四个古铜环依次亮起。每经过一个，玩家看见一段不属于自己的记忆：

1. 一只巨大的金色眼睛俯视围火而坐的人类，双方都把武器放在触手可及处。
2. 阿瑟妲从胸口剥下一片金鳞；人类、精灵与矮人工匠把七道金属誓环套上会呼吸的钟心。
3. 穿无徽灰袍的人在内圈刻入一行更小的命令：“被见证者服从见证者。”
4. 古龙用爪击碎晶体，七道光飞向不同方向；其中一道坠入尚未开采的黑砧山。

有 `ysolde_translation`、`gromm_confession` 或艾琳记录时，玩家能区分第三段是后加的。`truth = max(truth,3)`。没有这些线索，只知道长誓钟遭人篡改，`truth = max(truth,2)`。

### 制动危机

若无人留守或维修失败，铁索突然下坠。

1. **拉紧急链。** STR DC 13；成功全员受 1 点伤，失败玩家受 5 点、同伴受重伤。
2. **用工具卡住齿轮。** 消耗旧锤、战斧或校誓工具之一；自动停止，物品损坏。
3. **让索林/格罗姆处理。** 关系至少 0 自动成功；关系负值时他仍救人，但说“这不抵你欠的”。
4. **借残片力量。** 自动成功，`fragment_used +1; resonance +1`。索林路线徒手握住热链；艾德里克看见断裂前一秒的“记忆”；莉瑞尔让所有人同时相信该向左压笼。

→ `A2-MINE-06`

## A2-MINE-06 第四层

【旁白】第四层没有镐痕。矿道是某种更古老的生物或工具切出的，墙面光滑得能照出人影。十七名矿工分散站在通道里，没有受伤，也不回应呼喊。他们面朝不同方向，各自重复一句话。

“我早该带他走。”

“再多一点就够了。”

“让他闭嘴。”

三句话分别与旧雨骨、饥月骨、裂锤骨呼应。玩家靠近时，自己的那一句从所有矿工口中响起。

### 唤醒矿工

1. **按名单逐个呼名，告诉他们此刻身在何处。** 〔有 `workers_list`〕
   - INS/WIL DC 13；成功唤醒十二人，失败唤醒六人且玩家压力 +1。

2. **让同伴讲一个只属于自己的真实记忆。**
   - 关系至少 +1时同伴照做，唤醒八人并使双方关系 +1。关系较低时同伴拒绝暴露软肋。

3. **用疼痛强行打醒。**
   - STR DC 10；能快速唤醒十人，但两人受伤，`cruelty +1`。凯尔或艾琳相关关系下降。

4. **用残片压过第四层声音。**
   - 唤醒全部十七人，`fragment_used +1; resonance +2; corruption +1`。玩家立刻触发专属高压侵扰。

5. **绕过他们直奔深处。**
   - 不耗时。若后援与升降架完好，他们可能被后援救走；否则在坍塌中产生伤亡。

矿工醒后描述：一名戴灰手套的人让他们在石门前“承认最想忘掉的事”，门便打开。他们中有人拒绝，于是托伦把拒绝者关上层。

→ `A2-MINE-07`

## A2-MINE-07 三面石门

石门没有锁，只有三块浅凹：圆戒形、细链形、齿轮形。无论当前玩家是谁，未同行的残片持有者会在此赶到，除非已死亡、被囚或关系为 -3。灰袍人的牵引把三人都带来。

### 重聚变体

- 友好：三人互相确认遭遇，决定轮流触门。
- 冷淡：各自守住容器，约定开门后再算账。
- 敌对：一人要求玩家先解除武装；需要第三人调停或交出一件抵押物。
- 某人缺席：石门只打开一半，玩家可用机械、炸药或自身残片补足。灰袍人不能替缺席者制造同意。

【灰袍人的声音】“回看者，渴求者，击破者。你们已经走得足够远。只要各自说一句真话。”

门要求三位持有者分别承认：

- 艾德里克：他保护家人也因为害怕再被留下，而不全是无私。
- 莉瑞尔：她想要真相，也想要一个能宣布她无罪的人。
- 索林：他维护承诺，也借承诺逃避自行判断后果。

玩家控制的角色可选择：

1. **承认真话。** `truth +1; fragment_pressure -1; defiance +1`。不是忏悔免罪，只是门不再能用秘密勒索。
2. **说一个体面的谎。** CHA DC 16；成功门暂时接受，`corruption +1; lied_at_door = true`；失败门把谎言用所有死者声音重复，压力 +1。
3. **拒绝回答，寻找机械开法。** INS/STR DC 16；有校誓工具降至 13。成功以结构力开门，`defiance +1`；失败触发落石，所有人受 2 点伤。
4. **逼另一持有者先说。** 关系 -1；对方是否照做取决于性格和好感。
5. **用炸药开门。** 门毁，`resonance +1`；失去阅读内侧警告的机会。

→ `A2-MINE-08`

## A2-MINE-08 照心室

【旁白】石门后是一座天然圆室。中央没有宝箱，只有一小片悬在半空的乳白晶体，像一只竖起的眼睛。它照见的不是外表。每个人脚下都拖着由记忆组成的影子：没救的人、说过的谎、尚未兑现的承诺。

墙上龙语与帝国语交叠：

> 第四骨名照心。照心不命令，不宽恕，只让代价被所有立约者看见。

灰袍人从晶体后走出。这次他有一张清晰的脸：瘦削、温和，像一位从不提高声音的宫廷教师。

【灰袍人】“我叫塞维兰。至少，曾经有人这样叫我。把你们带来不是欺骗。灰桥会毁灭，因为碎片拒绝成为整体。让我替你们承担选择。”

他提出把照心骨接入任一容器，使该持有者成为临时核心。力量足以命令矿区所有人撤离，也足以令帝国或托伦放下武器。代价是持有者从此不断感受附近所有人的欲望与记忆。塞维兰刻意不说：这只是四枚钟骨能拼出的“四声冠”，不是完整长誓钟。

### 选择

1. **亲手触碰照心骨。**
   - 播放 `A2-MINE-09` 的个人见证；获得 `fourth_fragment = true`。若无铅盒，压力 +1。该变量为稳定开发键，界面显示“照心骨”。

2. **让最信任的同伴触碰。**
   - 关系至少 +2 且明确同意才可。对方取得残片，玩家在终幕无法单方面决定其用途。

3. **把它收入铅衬工具盒。**
   - 有工具盒自动成功；无工具盒需 WIL DC 16并受 3 点伤害。`fourth_fragment = true; witness_contained = true`

4. **接受塞维兰的临时核心提议。**
   - 立即令矿工全部清醒、停止附近战斗；`fragment_used +2; corruption +2; temporary_core = true`。
   - 塞维兰看似消失，实际进入持有者意识；终幕夺权难度上升。

5. **尝试当场摧毁。**
   - 普通武器无效并反射 4 点伤害；有炸药可炸裂外壳，但残片化为光进入最近三名持有者，`resonance = 6`，强制提前终幕。

6. **不碰，带所有人离开。**
   - 石门在离开者身后重新合拢。灰袍人说“拒绝也是一种请求，只是由别人替你支付”。地面立即大震；玩家仍可逃，但进入 `A2-MINE-10-LEAVE`，灰桥危机无人缓解。

## A2-MINE-09 见证：你实际做过什么

触碰后，不播放固定善恶评价，而从本周目事实抽取三段。

### 第一段：你保住的

- 救彼得/妮芙/科德/矿工：显示获救者此刻的具体动作。
- 优先保货或证据：显示物品正在何处、它可能帮助谁。
- 什么都未救：显示玩家自己仍活着、呼吸急促。旁白不讽刺：“生存也是被保住的东西。”

### 第二段：你让别人支付的

- 被出卖的名单、被留下的伤员、被魅惑者、被杀俘虏、被扣证人中择最重一项。
- 若几乎无伤害选择：显示同伴因玩家的决定承担风险，例如留守绞盘或家人尚未离境。任何路线都不宣称代价为零。

### 第三段：你不肯承认的愿望

- 艾德里克：希望父亲死得有意义，因为毫无意义的死亡更难承受。
- 莉瑞尔：希望有人爱她到足以替她宣布那晚的沉默正确。
- 索林：希望世界真的只需按图修好，因为判断谁该受损比锻铁更难。

玩家回应：

1. **“是。这些都是我。”** → `truth = max(truth,4); fragment_pressure -1`。
2. **“我承认事实，不接受你的解释。”** → `defiance +1; truth +1`，见证仍成立。
3. **“只给我看失败，是为了让我服从。”** → 若 `shadow_named`，识破塞维兰剪辑记忆，`rel.shadow -1; truth +1`。
4. **要求看自己救人的后果。** → 残片展示好意也会产生伤害，玩家获得终幕“共同承担”选项所需理解。
5. **拒绝继续观看并借力关闭。** → `fragment_used +1; corruption +1`，跳过真相 4。

## A2-MINE-10 山腹裂开

【旁白】残片离开原位的瞬间，整座山像从梦中翻身。圆室顶部裂开，白色光从岩缝奔向升降井。远处传来铁索崩断与人群喊叫。更深处，一声不像声音的龙鸣穿过骨头。

塞维兰没有慌张。

【塞维兰】“这里不是长誓钟第一次开口的地方。矿道只是后来挖穿了一根传音脉。顺着古水道往东，去听城里没有钟体的第七声。”

这句话把雾钟城变成强线索，却仍不证明塞维兰可信。墙上的矮人测绘刻痕独立指向相同方向；有格罗姆或伊索尔知识时，玩家可验证矿山与城市地下确实由古水道相连。`sanctuary_clues +1`。

### 撤离分配

1. **让同伴带矿工上去，自己携残片沿古水道探向城市。**
   - `sacrifice +1`；玩家获得最快的城市地下入口，但终幕前暂时少一名同伴。

2. **全队沿古水道回城，交给后援撤人。**
   - 若此前安排后援或修好升降架，安全；否则至少六名矿工被困。

3. **命令矿工跟你进古水道当人手。**
   - 关系至少 +1时三人自愿；否则是胁迫，`cruelty +1`。

4. **使用临时核心命令所有人。** 〔`temporary_core`〕
   - 所有人无条件执行，撤离效率最高；`corruption +1`。玩家开始听不见别人说“不同意”的语气。

5. **趁乱携残片独自逃向地表。**
   - 进入 `A3-SHRINE-01` 的追逐变体；托伦、帝国和其他持有者全数追击。

## A2-MINE-10-LEAVE 拒绝见证

〔仅未取照心骨〕

玩家向上撤离时，矿工依次重新陷入三类情绪循环。升降井开始坍塌。可以在出口最后一次回头：

- **返回取残片。** 失去一格时间并受 3 点落石伤害，仍进入 `A2-MINE-09`。
- **救尽可能多的人后离开。** STR/INS DC 13，救出人数取决于升降架；随后进入逃离结局候选 `END-08`。
- **只保自己与私人目标。** 若路线通畅可成功逃离，`private_goal` 保持；灰桥结局固定毁坏。
- **把入口炸塌。** 延缓共鸣数小时，却把下层所有人封死。`cruelty +2; defiance +1`，进入 `END-09` 候选。

## A2-MINE-11 古水道岔口

【旁白】裂隙桥对面不是初鸣庭，而是一段比矿井古老得多的砖拱水道。水早已干涸，拱顶每隔一段便嵌着传音铜杆。所有铜杆都朝东——雾钟城。

哈兰、托伦、伊索尔、艾琳与格罗姆是否赶到由此前状态决定。他们仍会争夺照心骨，但争论焦点变成“带回哪里研究”，而不是所有人都凭空知道最终地点。

- 哈兰要求封箱送雾钟城静默署，承诺先撤工人。
- 托伦要求照心骨留在矿区，作为帝国不再炸矿的筹码。
- 伊索尔希望带去旧学院，与城市钟律资料比对。
- 艾琳建议先净化宿主症状，不把救城使命压给一个病人。
- 格罗姆只确认水道尽头有他年轻时从未见过的原型誓环结构。

### 选择

1. **沿古水道直接入城。** 最快获得河下入口，`sanctuary_clues +1`；只能带一名同伴与一名阵营代表。
2. **先回地表救人，再从正门进城。** 矿工存活增加，城市行动时间 +1，玩家可自由选择白塔、学院、河渠等治疗。
3. **把照心骨交给某方，自己只带样本离开。** 该方成为后续持有者；玩家仍被自身容器诅咒，不会因交出别的钟骨自动痊愈。
4. **拒绝带走照心骨，重新封门。** 黑砧共鸣被延缓；玩家获得矿尘样本，可完成学院稳定药，不必进入终幕。
5. **尝试在矿区直接治疗自己。** 用照心骨照出回声线可令 `curse_stage -1`，但无法切断；玩家清楚初始连接地点在城市方向。

完成矿区不是主线义务。玩家可在此选择长期服药、回城调查、契约转移、内化拆解或继续寻找初鸣庭。

→ `CITY-01`（正门回城）、`CITY-09`（交帝国）或 `CITY-10`（古水道快速入口）。
