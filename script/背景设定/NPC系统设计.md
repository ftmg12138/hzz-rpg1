# 《残片牵引》NPC 系统详细设计文档
**版本：1.0 完整扩展**  
**目标篇幅：** 深度主要NPC + 精细路人模块 + 传闻NPC资料，远超基础圣经中的概述。主角为普通人，NPC需更加鲜活、有矛盾、有私人历史。

---

## 1. 主要NPC（深度档案）

以下NPC均设计为比主角更有层次。每个包含：外貌与第一印象、详细背景与私人历史、核心动机与软肋、与残片/主线的关联、玩家可影响的态度分支、关键对话风格示例、可能的结局走向。

### 1.1 “银舌”瓦伦（Valen the Silver-Tongue）
**种族：** 人类，约40岁  
**外貌与第一印象：** 中等身材，总是穿得干净但略旧的商人外套，手指上有几枚不值钱的戒指。笑容很快，眼神却在说话时不停打量对方的口袋和表情。声音温和，喜欢用“朋友”称呼刚认识的人。

**详细背景：**  
瓦伦出生在帝国中部一个小商会家庭。年轻时曾是颇有前途的账房，因为一次帮上司掩盖账目漏洞而被迫离开。之后他靠贩卖“不一定真实但总是有用”的消息为生。十年前他的女儿艾拉（当时12岁）在边境一次“清剿行动”中失踪。官方说是被流寇掳走，瓦伦始终怀疑是帝国军队或某个地方军阀所为。他用之后所有积蓄和人脉寻找女儿，至今没有结果。这个执念让他既贪婪又偶尔会出现真正的柔软。

**核心动机与软肋：**  
- 动机：赚钱 + 寻找女儿的任何线索。  
- 软肋：任何关于“年轻女孩失踪”或“帝国边境暴行”的话题都会让他短暂失态。如果玩家早期帮助他寻找线索（即使是假的），好感会大幅提升；如果玩家利用他的女儿作为要挟，他会变得极具敌意且不择手段报复。

**与残片关联：**  
他曾经手过一块疑似残片相关的古物，但当时不知道价值，便宜卖了。后期可能成为获取情报或进入某些圈子的关键。他本人不追求残片，但知道谁在买。

**态度分支示例：**  
- 早期帮他打听女儿 → 中期提供真实情报，甚至愿意冒险。  
- 出卖或欺骗他 → 他会把玩家的行踪卖给帝国或仇家。  
- 杀死他 → 失去一个重要情报源，但可能从他身上搜到女儿的旧信物或账本。

**对话风格：**  
“朋友，这个消息值三个帝国兑换券。不过如果你是为了那个……失踪的女孩，我可以少收一点。只是少一点。”

### 1.2 修女艾琳（Sister Eilyn）
**种族：** 人类，28岁  
**外貌与第一印象：** 穿朴素的灰色教袍，头发总是整齐地束起。眼神清澈，说话慢而认真。手上有细小的烫伤疤痕（来自某次仪式）。

**详细背景：**  
艾琳出身边境农户，父母死于疫病后被当地小教堂收养。她真心相信教义中的“净化与救赎”，但三年前在一次秘密任务中接触到残片碎片。那次经历让她看到教派高层并非纯洁，有人想利用残片“加速神罚”。她没有举报，而是选择继续留在低阶位置观察。她定期去贫民区送药，也秘密记录高层的异常举动。

**核心动机与软肋：**  
- 动机：保护真正无辜的人，同时搞清楚残片是否真的是“神的工具”。  
- 软肋：如果玩家在她面前对弱者施暴或过度沉沦，她会失望并减少帮助；如果玩家展现出哪怕一点自我牺牲，她会愿意分享更多秘密。她自己也有信仰动摇的时刻。

**与残片关联：**  
她保管着一小块被“净化”过的残片残渣，可用于治疗或引发精神侧写。她不知道完整真相。

**态度分支：**  
帮助贫民或拒绝残暴选项 → 她提供治疗与情报。  
持续堕落或攻击教派相关人员 → 她可能告发或亲自对抗玩家。

### 1.3 矮人老匠人「格罗姆·铁须」（Gromm Ironbeard）
**种族：** 矮人，157岁  
**外貌与第一印象：** 矮壮，胡须编成复杂辫子并饰有金属环。手上全是老茧与烧伤。说话直接，不喜欢客套，但对真正的好工匠会露出欣赏。

**详细背景：**  
格罗姆年轻时是矮人城邦最有天赋的符文匠之一。他曾参与锻造一件与残片相关的古代武器，但那件武器后来被用于一场惨烈的内战，导致他的弟弟死亡。从此他拒绝再锻造任何“有可能被用于大规模杀戮”的符文武器，只做普通工具和防御性符文。索林（矮人主角）的家族与他有旧怨——索林的师父曾公开批评格罗姆“浪费天赋”。

**核心动机与软肋：**  
- 动机：守住自己的底线，同时不想看到更多矮人死于符文武器。  
- 软肋：如果玩家（尤其是矮人主角）真诚地请教而非索取力量，他会慢慢打开心扉。提及他弟弟或那件古代武器会让他沉默很久。

**与残片关联：**  
他知道一些古代铭文的解读方法，可能帮助理解残片上的符文。但他极度抗拒再次接触真正的残片。

### 1.4 精灵游侠「凯尔·晨星」（Kael Morningstar）
**种族：** 精灵（或半精灵），外观约30岁（实际更长）  
**外貌与第一印象：** 高瘦，银发常随意束起，穿实用的皮甲而非华丽精灵服饰。眼神锐利，说话简洁，经常先观察再回应。

**详细背景：**  
凯尔来自一个已经衰败的精灵边境哨所。他亲眼见过帝国扩张如何一点点蚕食精灵林地，也见过自己族人因为“保持中立”而坐视人类难民去死。他选择成为游侠，专门猎杀他认为“罪有应得”的人（军阀、奴隶贩子、腐化官员）。他的方法经常越界，因此被部分精灵长辈视为耻辱，也被一些人类视为英雄或恐怖分子。

**核心动机与软肋：**  
- 动机：用自己的方式阻止更多无辜者死去。  
- 软肋：如果玩家在他面前对明显的恶人仁慈，他会质疑玩家；如果玩家与他一起行动后突然选择屠戮无关者，他会翻脸。他内心其实渴望有人能证明“不必永远用血解决问题”。

**与残片关联：**  
他追踪过一个携带残片的帝国密探，因此知道残片正在被多方争夺。

### 1.5 帝国边境军官「哈兰上尉」（Captain Harlan）
**种族：** 人类，35岁  
**详细背景：**  
出身中等军官家庭，靠战功升上来。他真心认为帝国秩序是边境活下去的唯一办法，但也清楚上层的腐败。他手下有士兵开小差、有士兵虐俘。他自己尽力约束，但资源有限。玩家可以成为他的情报来源、威胁，或被他招募。

**软肋：** 他有一个在内地读书的儿子，担心边境战争升级后儿子被征召。

### 1.6 妓院老鸨「红牡丹」米拉（Mira the Red Peony）
**种族：** 人类，42岁  
**详细背景：**  
年轻时是边境最受欢迎的舞女，后来自己开了店。她保护手下的女孩（和少数男孩），同时与地方势力维持微妙平衡。她见过太多“想沉沦”和“被逼沉沦”的人。对玩家态度取决于玩家是消费者、保护者还是破坏者。

**软肋：** 她有一个被她偷偷送走读书的年轻女孩（可能与瓦伦的女儿线索有关）。

### 1.7 刺客「无面」斯凯（Skye the Faceless）
**种族：** 猫人或人类混血  
**详细背景：**  
靠杀人活命，但有自己的规矩：不杀孩子，不接“只是因为讨厌”的单。曾经是某个贵族的私生子，被抛弃后学会生存。玩家可以雇佣、被雇佣、或成为目标。

### 1.8 地方军阀「疤脸」托伦（Toren Scarface）
**种族：** 人类  
**详细背景：**  
控制一片边境矿山与通路。残暴但讲“自己的规矩”。他想摆脱帝国控制，成为真正的地方王。残片对他来说是筹码。

### 1.9 残片研究者「伊索尔学者」（Scholar Ysolde）
**种族：** 人类女性，50岁左右  
**详细背景：**  
前帝国学院学者，因为研究被禁的古代文献而被流放。她收集所有关于龙核的碎片信息，相信理解它比销毁或控制它更重要。她可能会请求玩家带物品给她分析。

### 1.10 矮人女商人「赫尔嘉」（Helga Stonehand）
**种族：** 矮人  
**详细背景：**  
格罗姆的远亲，更务实。她做武器生意，不在乎符文是否被用于战争，只在乎价格和信誉。可与格罗姆形成对比。

### 1.11 年轻帝国士兵「小汤姆」（Young Tom）
**种族：** 人类，19岁  
**详细背景：**  
刚被征召，害怕又想表现勇敢。可能在多个事件中出现，玩家的对待方式会影响他后来成为逃兵、忠兵或死人。

### 1.12 神秘旅者「灰袍人」（暂无真名）
**种族：** 不明  
**详细背景：**  
偶尔出现在酒馆或路上，说话如谜语。可能是残片意志的某种投影，或古代存在的代理人。从不直接战斗，只留下选择。

（以上12个均为可深度互动的主要NPC，每个都有至少3–5个主要态度分支和私人故事线钩子。）

## 2. 路人NPC模块化系统（精细版）

路人通过模块组合生成，且**必须根据当前地区 + 当前主线进度**调整说话内容。

### 2.1 外观模块（每种族3–5套）
- **人类边境：** 风尘仆仆的斗篷 / 破旧军装残件 / 农人粗布 / 商人稍好的外套 / 明显受伤包扎  
- **人类城市：** 整洁市民服 / 华丽但俗气 / 教袍 / 仆役制服  
- **精灵：** 实用皮甲 / 褪色的优雅长袍 / 旅行斗篷遮住耳朵  
- **矮人：** 皮革围裙 / 金属装饰辫须 / 矿工装备 / 商人厚重外套  
- **猫人：** 轻便短装 / 多口袋背心 / 部落图腾装饰  

### 2.2 性格模块
- 抱怨型：凡事先叹气，强调“又涨价了”“又死人了”  
- 赞美型：喜欢夸某人（可能是真的，也可能是怕）  
- 恐惧型：说话小声，频繁看周围  
- 投机型：立刻询问玩家是否需要向导/商品/消息  
- 冷漠型：只回答必要问题，不想多管闲事  
- 热心型：主动提供帮助或警告  

### 2.3 思想/立场模块（与地区和剧情联动）
- 支持帝国秩序  
- 痛恨征兵与税收  
- 相信龙灾是神罚  
- 只关心明天的面包  
- 同情精灵/矮人  
- 认为外来者都是麻烦  

### 2.4 地区 + 剧情联动规则（核心）
系统在生成路人对话时，读取：
- 当前地点标签（边境小镇、矿山、精灵林地边缘、帝国前哨、城市贫民区、酒馆等）
- 当前主线标志位（例如：是否已发生“商队袭击”、是否已有“帝国增兵”、是否已传播“某军官暴虐”传闻）

**示例：**
- 在边境小镇 + 已发生商队袭击事件：路人会说“听说北路的商队又被劫了，这次死了好几个，帝国的人来了只收税不抓人。”
- 在矿山 + 军阀托伦势力强：路人会抱怨“疤脸的人又来收保护费，不给就砸炉子。”
- 在城市 + 玩家近期做了高调善事或恶事：路人可能提及“最近有个外地人……”的模糊版本。

### 2.5 名字生成
维护种族名字池 + 可选后缀：
- 人类：Edric, Mira, Harlan, Lira, Toren, Eilyn, Tom, Bran, Sera, Kael… + 可选“son of”“the Miller”等
- 精灵：Liriel, Aelin, Sylvar, Elandor, Faelwen…
- 矮人：Thorin, Dwalin, Gromm, Helga, Brok, Kazra…
生成时确保同一场景内不重复。

## 3. 传闻中的NPC（书籍与简要资料）

这些角色永不直接出场，只通过书籍、铭文、路人闲聊、壁画出现。

### 3.1 学者伊拉斯谟（Erasmus the Chronicler）
**资料出现方式：** 玩家可在多个地点找到他的残本笔记或抄本。  
**内容示例（书籍摘录）：**  
“龙核并非神造，而是第一帝国的奠基者与某位古龙达成的契约之物。契约破裂后，核碎为七。持有者会听见‘方向’，但方向不一定通向救赎……我已跟踪三块，第四块的踪迹在边境矿山消失。若有人读到此页，请勿试图集齐，除非你准备好成为它的一部分。”

### 3.2 古代英雄/暴君「赤王」瓦伦提乌斯
路人会说“赤王当年也是从边境崛起的”，书籍则记载他如何利用早期残片统一了部分领地，最终被自己的将军背叛。

### 3.3 失踪的精灵领主「银叶」埃兰多
铭文与精灵游侠的闲聊中出现。据说他是最后一个真正理解古代精灵与龙核关系的人，百年前独自进入一处遗迹后再无音讯。

### 3.4 帝国开国皇帝的影子顾问
只在禁书或伊拉斯谟笔记中被隐晦提及，暗示龙核阴谋的真正设计者可能仍以某种形式存在。

## 4. 使用与生成建议

- 主要NPC使用独立档案 + 标志位系统管理态度。  
- 路人每次进入新场景或重要剧情节点后刷新对话池，确保“新闻”与当前事件同步。  
- 传闻内容可做成可收集的“笔记”或“书籍”物品，阅读后解锁背景信息或轻微线索。  
- 所有NPC对话避免上帝视角，尽量通过主角可观察到的行为与可询问到的内容呈现。

**文档结束。**  
本文件提供了12个深度主要NPC的完整骨架、精细的路人模块与地区/剧情联动规则，以及多个传闻NPC的具体资料示例。可直接作为内容填充与程序生成的依据。后续可继续为每个主要NPC补充更多具体对话分支。
