# 《残片牵引》主线剧情与对话分支设计文档
**版本：1.0 核心骨架（支持60-90分钟多分支流程）**  
**说明：** 本文件整合主线结构与对话/选择原则，形成可实现的网状剧情框架。选定主角后，另外两位主角以NPC形式存在并可互动。玩家需逐步收集残片（至少接触多块，最终面对集齐或放弃的选择）。所有重要选项的可见性由前期标志位 + 属性/碎片状态决定。场景按地图节点推进，进入节点时根据标志位刷新NPC状态与可用对话。

---

## 总体节奏与收集目标

- **开场：** 私人小目标 + 偶然获得第一块残片 → 第一次牵引与性格化弹窗。
- **中期：** 在NPC引导/冲突中逐渐明白残片与龙核的关联，私人目标与残片下落重叠。接触第2-3块残片线索。
- **后期：** 明确“集齐或销毁/放弃”的压力，面对最终选择。最终选项池由全程行为累积决定（例如高堕落路线出现“利用残片沉沦权力”，高牺牲路线出现“主动摧毁并承担代价”）。
- 其他主角：作为可招募/对立/旁观的NPC出现在特定节点，其态度同样受标志位影响。

**关键标志位类别（示例）：**
- `helped_valen` / `betrayed_valen` / `killed_valen`
- `showed_mercy` / `showed_cruelty` 计数
- `fragment_desire_high` / `fragment_anger_high` / `fragment_memory_high`
- `sister_alive` / `family_clue_found`
- `knows_dragoncore_truth` 等级（0-3）
- `corruption_level` / `sacrifice_count`

选项可见性规则：许多对话选项带条件（例如仅当 `helped_valen == true` 且 CHA修正 ≥ +1 时出现“用瓦伦的名义说服卫兵”）。

## 第一幕：开场与第一块残片（约15-25分钟）

### 场景节点1：私人目标进行中（地图：边境道路 / 小镇 / 工坊）
**人类（艾德里克）：** 护送小商队。  
**精灵（莉瑞尔）：** 在旧宅废墟搜寻遗物。  
**矮人（索林）：** 在客户处修理旧兵器。

**示例对话分支（人类开场）：**
- 商队领队抱怨帝国税收。  
  - [普通] “小心点就行。”  
  - [洞察相关 / 记忆碎片后强化] “我父亲也是被这样征走的……”（触发短暂闪回，+记忆标志）  
  - [激进] “要是有人敢拦路，我就先动手。”（+残酷倾向）

夜间遭遇埋伏。战斗或潜行/交涉后，从尸体获得戒指（人类）/银链（精灵）/怀表（矮人）。

**第一次碎片弹窗（强制）：**
- 人类：记忆闪回父亲离开的雨天，选项包括“握紧戒指继续走”“把戒指丢掉试试”“陷入沉默”。选择影响初期精神消耗与后续回忆频率。
- 精灵：欲望冲动（对附近幸存者或路人），选项包括靠近、压抑、利用。
- 矮人：愤怒（对袭击者或延误），选项包括砸东西、压抑、追击。

### 场景节点2：返回安全点 + 遇到第一个关键NPC
可能遇到瓦伦、艾琳、格罗姆或凯尔之一（根据主角与地点）。  
**示例（遇到瓦伦）：**
- 瓦伦主动搭话卖消息。  
  - [帮助] 询问他女儿的事并表示愿意帮忙 → `helped_valen = true`  
  - [利用] 用假消息骗他 → `betrayed_valen` 倾向  
  - [冷漠/伤害] 威胁或攻击 → 关系破裂，可能进入战斗  
  - [碎片影响选项] 人类可能突然提及自己妹妹而走神；精灵可能多一个引诱折扣的选项；矮人可能因为讨价还价而出现愤怒选项。

完成此节点后，私人目标部分达成或受挫，同时第一次明确感到“被什么东西推着走”。

## 第二幕：中期卷入（约25-40分钟）

### 关键推进点
- 私人目标与残片线索重叠（例如妹妹失踪线索指向残片交易、家族旧物与第二块残片有关、客户订单涉及军阀争夺残片）。
- 引入帝国军官哈兰、军阀托伦、修女艾琳、游侠凯尔等。其他主角以NPC身份出现（例如矮人主角路线中可遇到作为游侠的莉瑞尔，或人类路线中遇到工匠索林）。
- 玩家可招募临时同伴、背叛、牺牲或利用他们。
- 随机事件与沉沦选项密度上升（酒馆、妓院、黑市、街头冲突）。

**示例多分支场景：矿山或边境哨站冲突**
玩家需要通过一个被军阀或帝国控制的节点。  
可用手段取决于前期标志：
- 若 `helped_valen`：可用瓦伦的情报走黑路。  
- 若与凯尔关系好：可共同清除守卫（但凯尔会要求不滥杀）。  
- 若堕落倾向高：可直接贿赂或用身体/暴力解决，但增加 `corruption_level`。  
- 若愤怒/欲望碎片高：额外出现冲动选项（硬闯、诱惑守卫）。

**对话可见性示例：**
- “说服守卫放行”（需要 CHA修正 ≥ +1 或特定NPC背书）  
- “提起瓦伦的名字”（仅 `helped_valen`）  
- “用残片的热量威胁”（仅碎片相关标志高，且可能触发副作用）  
- “直接杀过去”（始终可用，但后果严重，影响后续多个NPC态度）

中期结束时，玩家至少接触到第二块残片的明确线索，并开始听到“龙核”“集齐会怎样”的只言片语（通过书籍、伊索尔、或传闻）。

## 第三幕：后期收束与最终选择（约20-30分钟）

### 汇聚节点
多个残片相关地点与势力汇合。之前的所有重要选择以以下形式回归：
- NPC是否愿意帮忙、出卖你、或已经死亡。
- 可用资源（情报、装备、安全屋）。
- 战斗难度与可用战术。
- 最终选项池。

**最终选择框架（选项可见性由全程累积决定）：**
- **集齐并试图控制**（需要高知识标志 + 一定力量/魅力，可能走向权力或被反噬）  
- **集齐后摧毁**（需要高牺牲计数或特定NPC支持，代价是私人目标失败或自身重伤/死亡）  
- **放弃并逃离**（若私人目标仍可完成，且堕落/抗拒牵引足够高）  
- **将残片交给某势力**（帝国、教派、军阀、学者，取决于关系标志）  
- **沉沦利用**（高腐败路线专属：用残片满足欲望/愤怒，成为地方恶霸或傀儡）  
- **自我牺牲封印**（高意志 + 高牺牲路线）

每个最终选项都有对应结局文本，并反映主角最终变成的人（而非简单善恶二元）。

**示例最终对话触发条件：**
- 仅当 `sister_alive` 且未严重背叛家人相关NPC时，出现“带妹妹离开，把残片扔进河里”的选项。  
- 仅当与凯尔或艾琳关系极好且 `showed_mercy` 高时，出现“一起摧毁并承担神罚”的共同结局。  
- 仅当 `corruption_level` 极高时，出现“让残片吞噬我，换取永恒的力量与欲望满足”。

## 对话与选择实现要点

- **心理活动：** 用斜体穿插在叙述中，强化主角视角（尤其碎片闪回时）。  
- **弹窗事件：** 独立于主对话，定时或在场景转换时检查碎片状态触发。  
- **状态刷新：** 每次进入地图节点，根据标志位更新NPC位置、态度、可用商品、新闻内容。  
- **其他主角作为NPC：** 在中后期节点出现，可进行深度对话，其个人故事线部分可被玩家影响，但不会抢走主线主导权。  
- **失败结局：** HP归零时根据当前节点与主要标志生成对应文本（战斗死亡、沉沦耗尽、被牵引至绝路崩溃等）。

## 内容填充建议

1. 先实现三个主角各自的开场节点 + 第一次碎片弹窗 + 第一个关键NPC相遇（完整对话树）。  
2. 再做2-3个中期核心冲突节点（带多标志位条件选项）。  
3. 最后做汇聚点与6-8个最终选项分支。  
4. 用路人模块填充过渡场景的新闻与氛围。  

按此骨架填充具体对话后，可稳定支撑60分钟以上的多分支体验，且前期选择会真实影响后期可见选项与结局。
