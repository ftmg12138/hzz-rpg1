# 《残片牵引》游戏设计圣经
**版本：1.1（碎片效果修正 + 护甲体质补充）**  
**目标：** 静态网页文字冒险游戏，主玩法为对话与选择，辅以轻量战斗与装备。一周目约 60–90 分钟。多主角（先实现人类/精灵/矮人），属性后台影响选项与结果，碎片以性格化方式持续扰动玩家。

---

## 1. 核心前提与主题

### 核心前提
远古存在（或帝国奠基者）曾锻造一件“龙核”（或称“命运之核”），用于与古龙沟通/约束。它并非单纯工具，而是带有残留意志，或本身是一场长期阴谋的载体（类似索伦锻造魔戒以备翻盘）。龙核被打碎成多块残片散落各地。

每一块残片会在接触者心中留下持续的“牵引”——模糊方向感、反复梦境、或“刚好”遇到的人或事。牵引不强制立场，只制造压力与相遇。玩家可以沉沦、当刺客、嫖娼、当街施暴，也可以挺身而出、慷慨解囊。残片会根据玩家的选择调整牵引的粗暴程度与表现形式。

主线不是“拯救世界”，而是：多方势力争夺残片以影响下一次龙灾或帝国命运。主角因偶然接触第一块残片而被卷入，私人目标（生存、保护某人、逃离、偿还）不断与残片下落重叠。即使刻意沉沦，也会被某种“巧合”重新推回相关节点。

### 主题
- 牺牲（真付出，而非口号）
- 对生存的渴望
- 友情的珍视与背叛可能
- 善恶自由（累积选择，而非阵营标签）
- 小人物被命运裹挟，但仍有选择空间

世界观宏大，但**从主角视角与心理活动展现**，不直接白话讲解。

## 2. 三位主角（详细背景与开局）

所有主角初始属性适中，差异通过背景、碎片效果与可选倾向体现。属性不显示面板，只通过选项可用性、说服成功率、战斗优势、受伤程度体现。

### 人类主角：边境斥候「艾德里克」（Edric）
- **出身：** 普通到略惨。边境小镇出身，父亲死于帝国征兵，母亲靠织补为生。曾为帝国做过短期侦察，见过腐败与残暴，也见过普通士兵的无奈。
- **初始动机：** 攒够钱带妹妹离开边境，或至少活过这个冬天。
- **碎片获取：** 护送商队时遭遇袭击，在尸体或废墟中捡到一枚暗淡戒指。
- **碎片效果（记忆与执念）：** 提升洞察与回忆相关选项。带着消极与忧伤色彩。会周期性触发闪回、强迫性回忆或 melancholy 情绪，影响对话（更回避、更尖锐地提起过去、或突然陷入沉默）。长期可能解锁家族或边境相关线索，但也会增加精神消耗。
- **心理呈现示例：** “戒指贴在胸口时，你又想起父亲离开那天的雨。你知道那已经是很多年前的事，但胸口还是发闷。”

### 精灵主角：流亡半精灵「莉瑞尔」（Liriel）
- **出身：** 惨。家族因牵涉古代残片事件被灭，自己因当时选择沉默（或出卖）而活下来，背负愧疚。外表接近精灵，但寿命与人类相近，被双方排斥。
- **初始动机：** 寻找家族被灭的真相，或试图赎罪/复仇。
- **碎片获取：** 在家族旧宅废墟中，从一本被烧毁的书里掉出一条细银链（或耳饰）。
- **碎片效果（魅力与堕落/欲望）：** 提升魅力相关选项（更容易说服、引诱、交涉）。每隔一段时间（或特定场景）弹出欲望事件：强烈想与异性亲近、用身体换取情报/通行、或在酒馆/妓院沉沦。选项包括顺从、压抑、利用、或暴力拒绝。顺从会短期提升相关检定，但可能损害关系或增加堕落倾向；长期压抑会让牵引更粗暴。
- **心理呈现示例：** “银链发热。你看着对面那个人的眼睛，突然觉得如果今晚不做什么，明天的事情会更难面对。”

### 矮人主角：工匠学徒「索林」（Thorin）
- **出身：** 普通偏富裕。矮人城邦工匠家族的学徒，负责给军队修装备。务实、重承诺，对“命运”毫无兴趣。
- **初始动机：** 完成一笔订单后回家，或偿还家族债务。
- **碎片获取：** 修理一件古代武器时，锤击使隐藏的怀表从内部掉出。
- **碎片效果（力量与愤怒）：** 提升力量与近战相关表现。周期性愤怒事件：对不公、拖延、欺骗突然失控。选项包括爆发、压抑、转化为工作狂、或针对特定目标。爆发可能赢得尊重或造成不可挽回的伤害。
- **心理呈现示例：** “怀表的齿轮声在耳边响。那个商人又在讨价还价。你的手已经握住锤子，脑子里只有一个念头：让他闭嘴。”

**自建扩展预留：** 后续可加猫人等，机制相同，碎片形式与扰动主题不同。

## 3. 主线结构（一周目约60-90分钟）

**三幕骨架（私人目标 → 卷入 → 收束）：**

1. **开场与第一块残片（15-20分钟）**  
   完成私人小目标过程中偶然获得碎片。体验第一次牵引与性格化弹窗。遇到1-2个关键NPC。可选择帮助、利用、无视或伤害。

2. **中期卷入（25-35分钟）**  
   残片下落与私人目标重叠。帝国、地方势力、教派、古龙相关者同时出现。友情/同伴线爆发（可招募、背叛、牺牲）。随机事件与沉沦选项增多。玩家开始察觉“总是被推着走”。

3. **后期收束（20-30分钟）**  
   多块残片相关节点汇聚。之前的选择以NPC态度、可用资源、情报真假、战斗难度形式回归。最终面对残片真相与自身变成的人。多种结局（不二元）：保住私人目标但付出代价、成为某种势力的工具、彻底沉沦但仍被牵引到终点、或做出真正的牺牲。

**贯穿元素：** 残片牵引始终存在。玩家越抗拒，遭遇越“巧合”且粗暴；越顺从，牵引越隐蔽。

## 4. 系统规则

### 属性（后台）
力量（STR）、敏捷（DEX）、体质（CON）、魅力（CHA）、洞察（INS）、意志（WIL）。  
不显示数值。修正值影响检定、伤害、选项可用性。详见《系统数值设计》文档。

- 高魅力：更多说服/引诱选项，欲望弹窗更频繁。  
- 高力量：战斗优势更大，愤怒选项更易出现。  
- 高体质：受伤更少，HP 更高。  
通过选择、装备、碎片、支线逐步提升。

### 体质与生命值
- HP 基于体质计算（详见系统文档）。  
- 随机事件、战斗、陷阱、碎片副作用等会造成伤害。  
- 护甲提供伤害减免。  
- **HP 归零即失败**，根据当前节点与主要选择给出对应失败结局文本。

### 武器系统（种族特色）
详见系统文档。人类实用平衡、精灵精准轻灵、矮人厚重破坏。其他类人生物（兽人、猫人等）有对应武器风格。装备受负重限制。

### 魔法系统
通用低阶 + 种族倾向/专属（精灵幻术与记忆、矮人符文、人类仪式等）。可通过支线跨种族学习。详见系统文档。

### 护甲系统
提供伤害减免，影响敏捷。轻甲适合精灵/猫人，重甲适合矮人。详见系统文档。

### 战斗（轻量互动）
推荐牌面比较或简化 d20。战力优势（属性+武器+碎片）降低操作难度或改善起始条件，但劣势仍有翻盘可能。结果回到叙事。

### 随机事件与弹窗
- 场景切换或定时触发。  
- 碎片相关性格化事件（人类：记忆/忧伤；精灵：欲望/堕落；矮人：愤怒）。  
- 路人新闻、政治抱怨等。  
- 沉沦选项始终可用，但影响关系、HP 与牵引。

## 5. NPC 系统

### 主要NPC（部分比主角更详细）
至少设计 8-12 个深度NPC，示例：

1. **“银舌”瓦伦（人类商人/情报贩子）**  
   表面友善，实则买卖任何信息。有一个失踪的女儿。玩家可帮助、利用、出卖或杀死他。他的态度会根据早期选择大幅变化，后期可能成为关键盟友或仇敌。

2. **修女艾琳（或教派低阶成员）**  
   表面纯洁，实际接触过残片。可提供治疗或情报，也可能利用玩家。有自己的信仰危机。

3. **矮人老匠人「格罗姆」**  
   索林的旧识或对手。掌握符文秘密。固执、重荣誉，但有不可告人的过去。

4. **精灵游侠「凯尔」**  
   正义感强，但方法激进。可能与玩家在暴力/仁慈选择上冲突。

（其他：帝国军官、妓院老鸨、刺客、地方军阀、残片研究者等。）

### 路人NPC（程序化）
模板组合外观、性格、思想。名字按种族特色生成。功能：传递新闻、抱怨、赞美、触发小事件。

### 传闻中的NPC（永不相遇）
通过书籍、闲聊、铭文呈现，营造更大世界感。

## 6. 对话与选择原则

- 选项包含正义、中立、激进/堕落。  
- 碎片影响通过额外选项或弹窗体现（人类偏忧伤回忆，精灵偏欲望，矮人偏愤怒）。  
- 重要选择设标志位，影响后续。  
- 心理活动强化主角视角。
