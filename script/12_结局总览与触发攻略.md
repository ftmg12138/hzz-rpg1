# 12 结局总览与触发攻略

> **完全剧透。** 本文件给开发、测试和希望查路线的玩家使用。条件写的是大方向，不公开后台精确计算式的部分会注明“约”。完整结局正文见 `10_结局_失败结局与后日谈.md`。

## 先理解三类结局

1. **个人治愈结局：** 玩家摆脱自己的诅咒后可以离开，不要求解决城市共鸣。代价通常由记忆、身体或另一个具体的人承担。
2. **初鸣庭结局：** 玩家找到雾钟城地下初鸣庭，处理钟骨连接、塞维兰与城市危机。
3. **退出或失败结局：** 玩家主动离开、延缓问题、被阵营接管、死亡或失去自我。它们也有完整后日谈，不是空白 Game Over。

## 如何摆脱“必须去矿区”的旧路线

黑砧不是必经。标准无矿区路径：

```text
序章 → 灰桥外镇 → 雾钟城
→ 白塔中止代祷，取得钟律线索
→ 档案馆查两份旧资料，取得地图线索
→ 同步六钟或直接定位第零蓄水池
→ 从白塔、档案馆、河渠或上环入口进入初鸣庭
```

黑砧的价值是：照心骨、较高真相、矿工关系和古水道捷径。完全不去仍能完成主要结局；若格罗姆、哈兰或托伦满足条件，他们会从另一条矿道取出照心骨并带到初鸣庭。无人代取时仍可完成代价更高的“三声断链”、封存、撤离或爆破，但“留史净化”和地方新约不可用。

## 七枚与四枚的区别

- 长誓钟在世界上总共碎成七枚钟骨。
- 第一部只有旧雨骨、饥月骨、裂锤骨与照心骨四枚进入事件。
- 另外三枚从未藏在雾钟城，不存在隐藏集齐路线。
- 四枚共同执行的是“四声解誓”：解除当前宿主强制连接、毁去服从铭文、平息本城共鸣，或建立可撤回的雾钟地方新约。
- 四枚不能复原长誓钟、召回阿瑟妲、重启覆盖第一帝国的完整盟约。

## 如何证明碎片不能简单丢

在 `CITY-02` 把容器锁进寄存柜、交同伴、扔河或卖掉，走出三十步。每名主角会出现不同离体症状。走到五十步会受永久小损失，但可以继续；容器不会无理由瞬移回来。此处让玩家自己决定回去取、转嫁或坚持离开。

## 个人治愈结局

| 结局 | 大概触发条件 | 主要代价 | 城市结果 |
|---|---|---|---|
| `END-CURE-01 被接走的病` | 在白塔完成转移仪式，让安瑟成为代祷器皿 | 安瑟继承诅咒；若未告知则构成欺骗 | 由其他持有者与阵营继续处理 |
| `END-CURE-02 每三天留下什么` | 接受伊索尔长期稳定方案并决定不追根源 | 每剂交出一段记忆，长期依赖药物 | 研究可能帮助病人，也可能被垄断 |
| `END-CURE-03 代价换了名字` | 完成河渠换命契，罗恩或他人知情同意 | 新宿主承担全部诅咒 | 玩家可离城，城市问题仍在 |
| `END-CURE-04 无法再丢掉的自己` | 西炉内化拆解至少一次检定成功；两次失败不可达 | 永久人格/身体副作用，不能再转移 | 玩家退出争夺，城市另行结算 |

### 白塔较正面的变体

先告诉安瑟全部风险，再迫使莫雷尔公开代祷者记录。安瑟仍可能自愿，但游戏不会把他的牺牲计到玩家头上，也不会称作无损好结局。

### 换命契真相路线

先保护莱欧娜或找到她藏的卷宗，证明罗恩被栽赃；再让米拉安置其女儿。此时罗恩通常会撤回同意。若玩家仍想转移，需要寻找另一名真正自愿且充分知情的宿主，不能靠魅惑绕过。

## 根源结局速查

| 结局 | 核心条件 | 关键限制 |
|---|---|---|
| `END-01 留下事实的人` | 誓环修复；四枚钟骨到场；真相至少 3，推荐 4；净化灰；伊索尔/记录能力；三名主角持有者付出记忆 | 高条件，三人都永久遗忘一段重要记忆 |
| `END-02 能够说不` | 誓环修复；识别服从铭文；有人留内环承担回声 | 四枚到场是标准四声解誓；缺照心骨可用三声断链，但承担者额外永久伤残且无法保留完整历史 |
| `END-03 未合拢的圆` | 真相 4；四枚钟骨均有明确且自愿的持有者；三名主角存活；未强夺容器 | 只建立雾钟地方新约；必须公开一项真实代价，没有“全保”选项 |
| `END-04 明天还要再问` | 新约基本条件满足，但一人关系低或存在已坦白的强迫 | 契约不稳定，关系不会自动修复 |
| `END-05 所有人都同意` | 夺权失败、强迫内环承担者或倒计时被塞维兰接管 | 主角失去主体；城市伤亡反而可能较少 |
| `END-06 四把钥匙` | 哈兰在场或联系帝国；交出本篇四枚钟骨 | 三项附带要求最多保住两项；黑库后患 |
| `END-07 离山更近的王` | 托伦存活且非致命敌对；交出四声冠或其控制权 | 无矿工契约时成为地方暴政 |
| `END-08 活着离开的人` | 从城市/初鸣庭侧道离开并保住私人目标 | 回声病未必解除；城市伤亡按疏散结算 |
| `END-09 石头不会回答` | 封死黑砧或一处入口，只延缓共鸣 | 数周或数月后城市井水再出现异常 |
| `END-10 互不相见的守护者` | 四名知情自愿者；分开封存四片 | 守护者不能再相聚；铅盒替代会留下后患 |
| `END-11 王座不会保持空白` | 在交接或对峙中杀死主要掌权者 | 后果取决于城市声望、矿工组织和武装方 |
| `END-12 只命令一次` | 夺取四声冠成功；腐化约 3 以下；自我辨认三轮至少两胜 | 成为活核心，长期承受他人情绪；不是完整长誓钟 |
| `END-13 没有杂音的歌` | 夺取四声冠成功；高腐化或继续删除反对意志 | 玩家成为局部情绪统治者，并非获得帝国级神器 |
| `END-14 复数的我` | 主动邀请塞维兰共治 | 自我边界逐年消失 |
| `END-15 最后的第七声` | 有炸药；安排撤离；玩家留内环点火 | 主角确定死亡，牺牲意义受公开证据影响 |
| `END-16 跑在火前面` | 有炸药和长引信；集体撤离 | 生还取决于全程关系/救援，不只最后骰子 |

## 最接近“好结局”的路线

没有无损完美结局。若目标是最低强迫、较少平民伤亡和保留公开历史，推荐：

1. 序章救下可救者，不用残片越过他人同意。
2. 灰桥保住至少一份书面证据，与两名未选主角坦白容器。
3. 雾钟城中止白塔不知情转移；学院取得钟律；保护莱欧娜公开污染事实。
4. 可选去黑砧：修升降架、释放囚犯、取得照心骨，不接受临时核心；若不去，需确保格罗姆、哈兰或托伦能代取。
5. 集齐钟律与地图两类线索，从档案馆或古水道进入。
6. 修复誓环，让三位主角持有者与照心骨持有者各自明确代价。
7. 有净化灰与完整记录时选 `END-01`；否则选 `END-03`。

这个路线仍会失去三段私人记忆，或让三人长期承担守约责任。

## 权力路线

想走完整邪恶/支配路线而非提前 Game Over：

1. 在序章至少使用一次残片解决实际问题，理解其效果。
2. 城市可做暗杀、双重勒索和静默署接管，提高腐化并获得资源。
3. 黑砧接受托伦带路或直接成为临时核心。
4. 初鸣庭允许塞维兰先说一句，修复誓环以提高可控性。
5. 夺取核心：保留自我进入 `END-12`，继续删除他人反对进入 `END-13`，邀请塞维兰进入 `END-14`。

高腐化不是自动失败；它改变玩家取得力量后愿意怎样使用。

## 帝国与托伦路线差异

### 帝国

优势是短期秩序、撤爆、正规文书和大规模运输；代价是黑库研究与政治掩盖。提交苔冠档案可逼哈兰公开旧案，但会牺牲第三项要求。哈兰关系高也不会同意把四声冠的控制权交给私人。

### 托伦

优势是矿区自治与地方执行力；代价是个人永久指挥欲。要得到相对受约束版本，必须：奥斯温存活、矿工关系至少 +2、持有账本，并由照心骨公开三年任期的真实代价。单纯与托伦好感高不会让他自愿放权。

## 城市支线奖励速查

| 支线 | 偏救助结果 | 偏利益结果 | 矛盾后果 |
|---|---|---|---|
| 倾斜的房子 | 租户会、扩容背带、声望 | 勒索奥多、拿钱箱 | 奥多既驱逐人也暗中少记租 |
| 无窗宅晚宴 | 听证、赔偿、宅邸入口 | 20—30票据、暗杀或出卖 | 瓦瑞克犯罪也真实资助病房 |
| 药瓶与小偷 | 四人分药、钥匙、声望 | 买下药铺成为债权人 | 妮玛救弟弟会让其他病人断药 |
| 被展览的家传物 | 可撤回借约、银屑护符 | 卖真品得20票据 | 归还家传物会削弱防洪预警 |
| 沉默证人 | 污染案与挪款案一并公开 | 暗杀得25票据、双勒索得32 | 莱欧娜犯罪不使商会证据失真 |

城市声望只影响准入、援手和后日谈，不直接开启最好根源结局。

## 三位主角私人目标

### 艾德里克

- 最稳：保父亲军信，另用商会担保或米拉身份办家人文书。
- 快速：把军信交哈兰换三人文书，代价是帝国销毁原件。
- 牺牲结局：在内环失去父亲记忆，家人仍可活着离开。

### 莉瑞尔

- 完整公开：账簿、帝国档案、科尔活口三者至少两项。
- 选择性公开：只拿命令页，能定帝国罪但隐藏母亲最初合作。
- 不公开：焚毁档案可保护活人，私人目标视为主动放弃，不是失败。

### 索林

- 合法完成：科德盖章或军务验货。
- 救人并免责：工棚账册证明订单被劫持。
- 假印：短期保住家业，留下哈兰把柄。
- 放弃：公开假单、救矿工，父亲失去帝国订单但不背欺诈债。

## 失败结局规避

- 北路、仓库和升降井保持至少一个同伴关系 +2，可获得一次代价救援。
- 不要在没有稳定药时连续做六次城市深入行动；诅咒阶段 5会触发失控。
- 把容器留远处前先准备同伴、药或回收路线；五十步后的损失不可读档外恢复。
- 检查站杀过士兵后不要指望投降保命；先用军令、汤姆或哈兰中止冲突。
- 爆破结局前完成疏散；否则即使主角生还，城市伤亡取最高档。
