# 05A 第二幕：雾钟城——先治好自己

> 这是重构后的中段核心。玩家离开灰桥外镇时只确认三件事：自己受到了会恶化的“回声病”；普通丢弃无法摆脱；雾钟城里至少有四种听起来可信的治疗。黑砧矿区从必经主线改为可选调查区。初鸣庭的存在、名称与位置都必须通过探索得知。

## 城市与时长

雾钟城位于灰桥南岸，旧帝国水道与商路在这里交叉。灰桥镇是它的北门外镇，黑砧矿区在西侧山腹。城市分六个可探索区：

| 区域 | 主要内容 | 治疗或线索 | 支线入口 |
|---|---|---|---|
| 锚门广场 | 入城、告示、旅店、声望反馈 | 离城试验、传闻汇总 | 倾斜屋、药铺窃案 |
| 白塔区 | 教会、钟塔、慈善病房 | 教会拔除术、钟律线索 | 圣髓失窃 |
| 书吏区 | 城市档案、学院旧馆 | 学者稳定术、古水道地图 | 沉默证人 |
| 河渠区 | 市集、浴场、船坞 | 黑市转移术、地下入口 | 猫人家传物 |
| 上环区 | 权贵宅邸、议事厅 | 城市封锁真相 | 无窗宅暗杀 |
| 西炉区 | 工坊、矿车总站 | 矮人拆解术、黑砧路线 | 欠薪工匠 |

标准周目可深入 3 个主地点并完成 1—2 个支线；探索型周目可做更多，但会让诅咒进入更高阶段。玩家若在序章与灰桥收集到两条快速线索，可跳过一部分调查直接锁定初鸣庭入口。

## 新核心状态

```text
curse_stage = 1          # 1-5；到5强制进入失控或终局
cure_leads = []          # church / scholar / transfer / forge / leave
sanctuary_clues = 0      # 0-3；2点可定位普通入口
city_rep = 0             # -3 到 +5
city_actions = 0         # 深入地点或完成支线通常 +1
anchor_severed = false
curse_transferred = false
```

`city_actions` 达 2、4、6 时各检查一次诅咒。玩家可以用稳定药延迟一次，但不能靠反复睡觉重置。

## 为什么不能把碎片丢掉

不要用一句“它会自己回来”结束。四层原因依次让玩家发现：

1. **回返。** 接触后的数小时内，容器会在睡眠、眨眼或换衣后回到身上。玩家仍可认为这是追踪魔法。
2. **回声线。** 城市医师发现残片在神经、记忆或心跳中留下对应节律。容器离体超过三十步，宿主开始失去功能。
3. **转嫁。** 任何人在宿主濒危时自愿接过容器，都可能成为新宿主；随手丢弃则会吸附到第一个以占有之心拾取的人。玩家必须面对“自己脱身是否等于把诅咒给别人”。
4. **追猎。** 帝国静默署、托伦买手与塞维兰追踪的是宿主留下的回声，而非首饰本身。即使暂时封存，追兵和梦境仍会找到玩家。

三位主角还有不同的生理表现：

- 艾德里克远离戒指会出现连续记忆断页。他第一次强行走出三十步后忘记母亲此刻的发色，回到戒指旁才恢复；再试可能永久失去一段记忆。
- 莉瑞尔的银链与“他人对她的注意”相连。远离后，同行者会短暂忽视她的声音，最后连她自己也无法确认身体边界；若强行转移，最后一个真心回应她的人最容易被链子选中。
- 索林的怀表与心跳、肌肉冲动同步。远离时心律逐渐漏拍，力量先暴涨再衰竭；砸毁表壳会让无形齿轮声进入胸腔。

这些机制既提供存活理由，也保留真正的逃脱方案：教会可转嫁、学者可长期稳定、黑市可契约转移、矮人可内化拆解、初鸣庭可处理根源。玩家不是被作者告知“只能去初鸣庭”。

## CITY-01 过桥入城

【旁白】从灰桥外镇到雾钟城只需穿过一座石桥，却像从一个坏消息走进许多个坏消息。北岸房屋低矮，南岸城墙上叠着六座不同时代的钟楼。每座钟的形状都不同，没有一座在整点同时响。

桥中央设着临时检疫棚。告示写：近期出现“矿尘性梦游”，症状包括重复旧事、异常亲近、暴怒、听见齿轮声。患者应自愿登记，由城市静默署安置。

队伍前方，一名登记过的男人被灰衣吏员带进无窗马车。他妻子问去哪里，吏员回答“治疗所”，却不给地址。

### 选择

1. **如实登记症状。**
   - 获得免费诊断牌与白塔病房地址；`quiet_office_marked = true`。灰衣吏员暗中记下容器形状。
2. **隐瞒并正常入城。**
   - CHA DC 13；成功无人注意，失败因残片发作被单独带去检查，仍可由同伴担保或逃走。
3. **跟踪无窗马车。**
   - DEX/INS DC 13；成功得知患者被送往书吏区地下旧馆而非医院，解锁静默署调查；失败增加城内警戒。
4. **先问被带走者是否自愿。**
   - 吏员说“他签了字”。妻子说他发作时连自己名字都写错。玩家可当场阻止，触发非致命冲突并 `city_rep +1`，但入城身份暴露。
5. **使用已有通行身份。**
   - 哈兰文书、米拉伪证或托伦木牌均可快速入城，并决定最初接触的阵营。

进入后，广场公告栏提供五条“治疗传闻”：白塔拔除、学院稳定药、河渠换命契、矮人拆表和“离开矿尘范围自然痊愈”。系统把它们都列为可追踪目标，不标真假。

## CITY-02 锚门广场：第一次主动丢弃

广场中央的铁锚据说来自一艘从未到过海的船。玩家可在旅店房间、寄存柜或铁锚下主动测试抛弃容器。

### 选择

1. **锁入商会寄存柜，走到广场另一端。**
2. **交给可信同伴保管，独自走远。**
3. **扔进河渠。**
4. **卖给古物商并立刻离开。**

无论方式，走到第三十一步触发个人症状。玩家可坚持到第五十步：HP 上限临时减半，并永久随机失去一项小记忆、一次他人注意或 4 点体力，容器不再自动回返，而是必须主动取回。这一点很重要：系统允许玩家真的把它留在原地，但代价证明“回去拿”是角色基于生存做出的选择，不是物品凭空传送。

若卖给古物商，对方在玩家折返前已经戴上：

- **说明危险并买回。** 退还钱并额外赔 2 票据；商人惊恐但存活。
- **强抢。** 取回并 `city_rep -1`。
- **任由商人承受，自己撑着离开。** 三十分钟内玩家症状减轻，商人开始呈现同类诅咒；解锁真实的“转嫁离城”路线。

完成本节点后 `cure_leads` 全部显式开放，玩家知道自己的目标是寻找能接受的解法。

## CITY-03 白塔拔除术

白塔医院由艾琳的上级、圣务长莫雷尔管理。莫雷尔没有邪恶外貌；他亲自搬病床，也准确记得每名病人的姓名。见到残片后，他承诺仪式能“让异物离开灵魂”。

关键人物是十七岁的见习生安瑟。安瑟说自己愿意成为仪式中的“代祷器皿”，因为教会从疫病里救过他。若私下询问，他并不知道器皿会继承诅咒，只以为会发烧几日。

### 调查仪式

- 阅读旧记录：INS DC 13，发现过去六名患者均痊愈，六名代祷者此后被送往无地址的静修院。
- 问艾琳：她直说这是转移，不是拔除；莫雷尔辩称“自愿承担也是治疗”。
- 让莫雷尔亲自当器皿：他拒绝，理由是自己必须继续救更多人。这暴露其计算，但不证明所有工作虚假。
- 与安瑟谈家人：他没有亲属，最害怕离开教会后无人需要自己。

### 仪式选择

1. **完整告知安瑟后再问。**
   - 他会害怕、犹豫。若玩家不施压，他最终仍可能同意，但要求教会公开照料所有代祷者。`sacrifice` 不归玩家，结局必须尊重是安瑟付出的。
2. **保持沉默，接受转移。**
   - 玩家真实痊愈，`curse_transferred = true`。可立即进入 `END-CURE-01`，也可因愧疚继续调查初鸣庭。
3. **中止仪式。**
   - `rel.eilyn +1; city_rep +1`。安瑟带玩家去钟楼透气，无意中指出六钟从不齐响的结构，获得 `sanctuary_clues +1`。
4. **让莫雷尔用空白圣髓瓶承载。**
   - 需要从支线取得真圣髓瓶或净化灰；成功只能封住一小时，期间玩家可远离容器而不发作，足够探索静默署。
5. **借仪式反向读取失踪代祷者。**
   - WIL DC 16；成功看见他们在城下水道维护一座残缺誓环装置，获得初鸣庭入口方向；失败诅咒阶段 +1。

## CITY-04 学院稳定术

伊索尔在书吏区旧学院租了一间屋，门上贴着“不是诊所，别在这里死亡”。她与药剂师达莫斯共同制作回声抑制剂，配方需要白井沉淀、黑砧矿尘和宿主自愿提供的一段真实记忆。

【伊索尔】“它不是解药。它能让你三天内听见自己的声音。三天以后再喝。长期副作用我没有长期数据。”

### 选择

1. **提供材料并服药。**
   - `curse_stage -1`，接下来两次城市行动不恶化；一段小记忆变得模糊。可走长期受试者结局 `END-CURE-02`。
2. **拒绝交记忆，用别人样本。**
   - 若偷取登记患者样本，药同样有效但对方症状恶化；`corruption +1`。
3. **帮助改进配方。**
   - INS/WIL DC 13；成功发现钟楼低频能替代部分矿尘，得到 `bell_resonance_clue` 与 `sanctuary_clues +1`。
4. **毁掉研究。**
   - 阻止静默署取得配方，但也让已依赖药物的患者失去来源。伊索尔敌对，城内病患新闻恶化。
5. **要求永久方案。**
   - 伊索尔列出三种理论：切断回声线会伤宿主、转给新宿主、找到最初建立连接的地方改写连接。第三种的城市档案索引为“第零蓄水池”，解锁 `CITY-07`；此时她还不知道“初鸣庭”一名。

## CITY-05 河渠换命契

黑市仪式由斯凯介绍，执行者是失去行医资格的猫人术士萨芮。她不骗人：诅咒可以转给一名理解风险、自愿接触容器的人，原宿主会痊愈，新宿主承受余下全部。

候选人罗恩是待处决的囚犯。他同意换取二十张票据寄给女儿。城市说他杀了税吏；罗恩说自己只在税吏殴打女儿时推了一把。卷宗缺失关键证词。

### 选择

1. **相信判决，支付罗恩并转移。**
   - 玩家痊愈，女儿获钱；罗恩不再被处决，而被静默署带走研究。进入 `END-CURE-03` 或继续调查。
2. **查清案件。**
   - 去书吏区找证人莱欧娜或完成“沉默证人”支线。真相是税吏倒地后被自己同伙灭口，罗恩被栽赃。
3. **告知罗恩即使获释也会终身被诅咒。**
   - 他问：“我女儿能知道钱从哪来吗？”若允许写信，他仍可能自愿；若米拉能安置女儿，他改为拒绝，不再需要用生命换钱。
4. **欺骗他风险很小。**
   - CHA 自动成功，因为他想相信；`corruption +2`。
5. **把契约用在自愿的强敌或垂死者身上。**
   - 只能对真正理解并明确同意者使用。战斗中强塞容器不会完成转移，只会造成双方共鸣。

该路线证明“摆脱诅咒”的其他办法确实存在，只是代价落在另一个具体的人身上。

## CITY-06 西炉拆解术

格罗姆与城市机械师梅芙在西炉区测试容器。他们认为可以把外部容器拆开，把回声线固定在宿主体内，再切断追踪频率。好处是塞维兰与其他残片难以定位；坏处是诅咒成为身体永久器官，无法再转移或用普通仪式拔除。

### 选择

1. **接受内化。**
   - 进行 CON/WIL 双检定。两次成功：玩家摆脱牵引与追猎，但永久保留人格副作用，进入 `END-CURE-04`候选。
   - 一次失败：HP 上限永久 -4，仍内化成功。
   - 两次失败：容器破裂，诅咒阶段升至 5，必须赶往城下的连接源头。
2. **先做无损拆解实验。**
   - 需要城市支线取得精密夹具或黑砧纯铁；成功得到四环结构图，`sanctuary_clues +1`。
3. **要求格罗姆替你决定。**
   - 他拒绝：“我能告诉你哪根线会断，不能替你决定断哪根。”
4. **砸毁容器。**
   - 可实际执行；容器碎，力量进入身体，触发双失败结果。系统不让物品无理由复原。

## CITY-07 第零蓄水池档案

书吏区城市档案馆每天只开放到钟响十下。馆长贝尔蒙坚持手续，因为最近有人偷走旧城图。玩家可凭高声望、伊索尔介绍、哈兰文书进入，也可行贿、潜入或完成档案馆支线。

相关资料分散在三份看似无关的文档：

- 建城水利图：七座蓄水池编号从一开始，没有第零。
- 钟塔维修账：每四十年更换一次“地下传音杆”，费用由不存在的龙语学会支付。
- 贵族地契：上环无窗宅地下的一块圆形土地不属于任何家族，只写“共同见证地”。

找齐两份即可得 `sanctuary_clues +1`并定位旧城下方的大致范围；三份齐全可直接找到档案馆书架后的测绘井，作为无战斗入口。

若前文已有快速线索：艾德里克父亲军信的路线编号、莉瑞尔账页的“灰桥见证者”、索林怀表四环工匠记号，每项可替代一份资料。认真铺垫的玩家能在一次访问内锁定。

## CITY-08 六钟错拍

白塔区六座公共钟永远错开半拍。登上主钟楼观察，会发现它们并非计时误差，而是在避开一个不存在的第七拍。玩家需要让六钟暂时同步，缺失的声音便从地下传来。

### 办法

- 有钟律线索或格罗姆结构图：按正确次序拉绳，自动成功。
- 靠 INS 观察：DC 16，失败触发错误低频，诅咒阶段 +1并惊动静默署。
- 让怀表/戒指/银链带路：自动发现第七拍，使用残片 +1。
- 贿赂六名钟工同时敲：花 12 票据且 `city_rep -1`，会让全城听见异常。

成功时，锚门广场铁锚、河渠旧浴场与上环无窗宅的井盖同时震动。`sanctuary_clues +1`。玩家明白入口不止一个，城下设施藏在城市结构中，而不是矿山终点。若已有两条真相线索，伊索尔才译出其古名“初鸣庭”。

## CITY-09 静默署

静默署在书吏区地下旧馆研究登记患者。他们给病人稳定药，也把病人绑在铜椅上记录发作。负责人赫斯医官相信少数人的非自愿实验能避免全城灾难；他不是塞维兰信徒，但实验资料正在被灰袍人格利用。

关键人物是桥上被带走的病人费恩与负责记录的年轻书吏莱欧娜。

### 进入

- 跟踪马车或持诊断牌：以患者身份进入，装备被寄存。
- 莱欧娜支线友好：从抄写室进入。
- 档案馆测绘井：绕到实验层后方。
- 高城内警戒：被捕后自动进入，但处于束缚状态。

### 选择

1. **释放全部患者。**
   - 需处理两名守卫和药柜；`city_rep +1`，未稳定患者在街上可能发作。
2. **只带费恩与愿意离开者。**
   - 大多数病人因害怕拒绝；玩家不能替他们算作获救。
3. **与赫斯交易实验数据。**
   - 允许一次非致命测试，换取回声线图。测试使诅咒阶段 +1，得到 `sanctuary_clues +1`与终幕抗夺权优势。
4. **揭露给公众。**
   - 需要莱欧娜证词或原始记录；城市声望 +2，白塔与议事厅互相推责，静默署暂停但资料可能被转移。
5. **接管机构为自己服务。**
   - 高腐化路线。强迫病人继续试验，快速得到所有城内主线线索，`corruption +2; city_rep -2`。

## CITY-10 找到入口

当 `sanctuary_clues >=2`，或完成任一快速路径，玩家可选择入口：

1. **档案馆测绘井。** 最安静，需档案权限或潜入；直接到见证廊，跳过入口守卫。
2. **白塔无声井。** 能带教会与艾琳，需同步六钟引出第七声；塞维兰提前知道玩家进入。
3. **河渠旧浴场。** 米拉/斯凯路线，可携带违禁物与逃生船；有水下机关。
4. **上环无窗宅地窖。** 需完成暗杀/权贵支线或盗钥匙；最接近誓环，但会遇到私人卫兵。
5. **黑砧古隧道。** 完成矿区部分内容后开放；能带矿工、格罗姆和照心骨，路长但真相信息最多。
6. **强行追随钟骨回响。** `curse_stage >=4` 可见；自动找到最近入口，玩家受 4 HP与一次人格侵扰。

### 此时玩家知道什么

低真相玩家只知道地下的连接源头“可能”能切断回声线；高真相玩家才知道长誓钟、塞维兰和雾钟城的四枚钟骨，并明确另外三枚不在本地。界面目标始终写成“前往城下源头，尝试解除回声线”，不写“拯救世界”“重铸长誓钟”或“集齐七枚”。城市共鸣与灰桥危机在玩家深入后才变成必须一起处理的后果。
