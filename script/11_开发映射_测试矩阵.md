# 11 开发映射与测试矩阵

## 数据拆分

推荐每个文本节点存成一条数据，字段如下。字段名只是契约，不要求采用任何前端框架。

```text
id                唯一节点 ID
title             玩家可见标题
body              默认正文
variants[]        条件文本变体，按 priority 从高到低首个命中
choices[]         选项数组
choice.label      玩家可见选项
choice.show_if    显示条件
choice.enable_if  可点条件；不满足时可显示原因
choice.check      属性、DC、优势来源
choice.results    success / failure / critical_success / critical_failure
choice.effects[]  原子状态变化
choice.next       下一节点
on_enter[]        进入时状态检查
tags[]            地点、人物、危险、休息、随机池标签
```

正文、条件与数值分开存。不要在一大段 HTML 中解析变量；文本可独立校对，逻辑可独立测试。

## 条件优先级

同一节点同时满足多个变体时使用：死亡或缺席 > 主角专属 > 不可逆背叛 > 高关系 > 普通关系 > 默认。结局拼接按“终局方案—城市—私人目标—NPC”执行，防止 NPC 小尾声覆盖主结局。

## 重构后主流程

```text
选角
→ 角色序章
→ 灰桥外镇两处调查
→ 东仓夜袭
→ 得知多种治疗传闻
├─ 雾钟城自由调查
│  ├─ 白塔转移
│  ├─ 学院稳定
│  ├─ 河渠换命
│  ├─ 西炉内化
│  ├─ 静默署调查
│  └─ 城市支线
├─ 黑砧矿区可选调查 → 回城或古水道捷径
└─ 离城/丢弃试验

取得两条初鸣庭线索或一条快速路径
→ 选择城市地下入口
→ 初鸣庭
→ 根源结局

任一真实替代疗法也可直接进入个人治愈结局
```

旧文档中若仍出现“完成灰桥后必去黑砧”，以 `04` 文件重写后的 `A1-TOWN-10` 和本流程为准。黑砧节点 ID 保持 `A2-MINE-*`，因为 ID 只标内容层级，不表示必经顺序。

## 诅咒循环

每次城市深入行动后：

1. `city_actions +1`。
2. 若稳定药保护次数大于 0，消耗一次，不提升 `curse_stage`。
3. 否则在行动数 2、4、6时 `curse_stage +1`。
4. 按主角与阶段抽取侵扰，不连续重复。
5. `curse_stage >=4`开放残片强引入口；`curse_stage >=5`触发城市失控节点。

转移成功会设置 `curse_transferred` 并停止玩家诅咒循环，但新宿主仍按世界状态推进。内化成功会停止回返与追猎检查，保留人格侵扰的低频文本。

## 初鸣庭定位

`sanctuary_clues` 可由以下来源获得，每类最多 1 点：

- 钟律：白塔中止代祷、学院研究或同步六钟。
- 地图：档案馆两份资料、莱欧娜权限或个人快速线索组合。
- 地下结构：静默署回声线图、河渠测绘、无窗宅地契。
- 矿道：黑砧古水道与照心室测绘。

普通进入需要任意两类。以下为单条快速路径：

- 三位主角专属旧证据中至少两项被带到档案馆。
- 黑砧完整探索并沿古水道进入。
- 高诅咒顺着牵引强行定位。
- 上环支线取得宅邸钥匙，同时掌握共同见证地契。

## 必测路线

### T01 艾德里克：个人优先

救彼得 → 回家拿信 → 以军信换文书 → 入城尝试白塔 → 知情后仍接受安瑟代祷 → `END-CURE-01`。验证家人离城、安瑟后日谈和城市危机交给其他人处理。

### T02 艾德里克：根源处理

保住军信 → 学院取得钟律 → 档案馆用路线编号快速定位 → 委托友好格罗姆从维修井代取照心骨 → 四声解誓并失去父亲记忆 → `END-01/02`。验证玩家不亲自进入黑砧也能让第四骨通过明确行动到场，并验证莉莉描述父亲尾声。

### T03 莉瑞尔：拒绝转嫁

公开母亲完整账页 → 救妮芙 → 停止教会转移 → 查清罗恩冤案并拒绝换命 → 取得或由 NPC 带来照心骨 → 与凯尔订立雾钟地方新约 → `END-03`。验证结局只约束本地四枚，不声称完整长誓钟复原。

### T04 莉瑞尔：真实治愈但道德代价

魅惑布兰 → 出卖米拉地址 → 欺骗罗恩风险 → 转移后离城 → `END-CURE-03`。验证不会强行让诅咒回到玩家，代价落在罗恩与女儿。

### T05 索林：矿区优先

救科德并造承重扣 → 入城西炉做无损实验 → 去黑砧修升降架 → 古水道定位 → 毁服从铭文并失去惯用手 → `END-02`。

### T06 索林：个人内化

保住订单 → 西炉直接内化双成功 → 不进入初鸣庭 → `END-CURE-04`。验证城市后日谈仍结算，不强迫继续主线。

### T07 城市善行不等于完美

救倾斜屋所有人 → 公开奖册 → 替妮玛付药 → 保护莱欧娜并同时公开其挪款 → 城市声望高。验证只给资源与准入，不直接增加牺牲、不自动开放最好结局。

### T08 城市犯罪路线

拿塞拉钱箱逃 → 暗杀瓦瑞克 → 卖掉银指 → 杀莱欧娜领赏。验证钱与黑市入口可用、城市声望降低、主线仍可通关但公开协作方案受限。

### T09 黑砧非必经

全程不去黑砧 → 由白塔钟律 + 档案馆地图定位 → 河渠入口进初鸣庭。分别测试两种状态：

- 格罗姆/哈兰/托伦满足代取条件：照心骨由明确 NPC 带到，开放完整四声解誓。
- 无人满足代取条件：照心骨缺席，只开放三声断链及低条件方案，关闭留史净化、地方新约和稳定四人封存。

验证黑砧可选，但照心骨不会瞬移或被无名 NPC 自动补齐。

### T10 城市非穷举

只访问两个主地点，通过序章快速线索定位 → 进入初鸣庭。验证玩家不必刷完所有地区。

### T11 丢弃逻辑

把容器卖给古物商 → 坚持远离至症状严重 → 回购。验证容器没有瞬移；玩家付出永久小损失；商人状态一致。

### T12 转移后继续调查

完成换命契但不结束 → 玩家无诅咒进入初鸣庭帮助新宿主。验证钟骨持有权和主角身份分离，终局选项需新宿主同意。

### T13 关键 NPC 死亡

杀伊索尔、格罗姆或艾琳之一，另两条疗法仍可用；高条件 `END-01`按缺失资源关闭并显示具体原因。

### T14 倒计时耗尽

做全部五条支线且不用稳定药 → 诅咒阶段 5 → 城市失控 → 接受静默署或强引初鸣庭。验证不会无限自由探索而没有代价。

### T15 无钱无武器

消费全部票据、丢失武器 → 通过声望、工作交换、潜行或投降仍能取得两条线索并到达至少一个结局。

### T16 四枚与七枚边界

把真相、声望、关系与探索全部设为最高，遍历所有隐藏选项。验证：

- 第一部物品表与场景中最多只有旧雨骨、饥月骨、裂锤骨、照心骨四枚。
- 界碑骨、远潮骨、空座骨只出现在历史说明，不生成物品、持有者或槽位。
- 任意结局不得写“集齐七枚”“重铸完整长誓钟”“召回阿瑟妲”或“恢复帝国盟约”。
- `END-03` 只能称“雾钟地方新约”；`END-12/13` 取得的是局部四声冠。

## 不可达与矛盾检查

- `curse_transferred = true` 时，不再显示“自己的容器发热”，改为新宿主状态。
- `anchor_severed = true` 时，不再允许普通转移或教会拔除。
- 安瑟死亡、离城或敌对时，白塔不得凭空生成另一名无名代祷者；需要等待或关闭。
- 罗恩真相查明且女儿安全后，他通常拒绝转移，除非玩家尊重其新一次明确同意。
- 黑砧未去时，玩家可知道初鸣庭，但不得获得矿区救援成果；照心骨只有在格罗姆、哈兰或托伦满足代取条件时才能到场，并必须记录持有者。
- 初鸣庭入口在城市，不得从矿区节点直接显示“门后就是初鸣庭”；必须经过古水道或返回城内。
- `four_bones_present = false` 时，关闭 `END-01`、`END-03` 与 `END-10` 稳定版，并把方案一切换为三声断链文本。
- `four_bones_present = true` 时，必须同时满足 `witness_holder_known = true`，不得出现无人持有的照心骨。
- 支线 NPC 死亡后，相关商店、证词、后日谈同步变更。
- 私人目标已 `abandoned` 时，终幕不得用临时幻象自动恢复。
- 强迫同伴牺牲后，不允许进入标注“自愿”的新约结局。

## 文本与时长验收

- 主路径首次阅读每分钟按 350—500 汉字估算；选择与战斗操作另计。
- 目标路径应包含 16—24 个主节点，城市深入 2—4处，随机事件 2—4个，支线 1—2条。
- 快速路径 45—55 分钟，标准路径 60—80 分钟，探索路径可超过 100 分钟。
- 不以总文件字数代替可玩时长；同一周目不可把互斥分支全部计算进去。
- 所有主线检定失败必须有 `next`，不得原地重掷。
