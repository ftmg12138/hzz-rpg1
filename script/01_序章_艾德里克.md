# 01 序章：艾德里克——雨没有停过

> 预计游玩 12—16 分钟。核心损失选择：救人、保货、追凶三者只能优先一项。序章无论如何都会抵达灰桥，但玩家带去的关系、钱、伤势与证据不同。

## E-PRO-01 北路黄昏

〔进入〕选择艾德里克。

【旁白】雨从下午开始下，到黄昏已经不像天气，更像一件覆盖世界的旧衣裳。车轮在泥里切出两道发亮的沟，五匹驮马轮流打滑。灰桥镇的木墙就在南边山坳里，隔着不到一小时的路，可那几盏守门火把始终没有变大。

你走在第二辆货车左侧，靴底每一次拔出泥浆都会发出吸吮声。商队领头人玛拉披着油布，坐在车辕上核对账本。她把尾数念了第三遍：“到镇，二十八张商会券。死马扣四张，丢货按价赔。你我都希望今晚别生事。”

二十八张。加上存在灰桥杂货铺的那笔，够给母亲和莉莉办两份冬季离境文书，还差你自己的。你可以先把她们送走。你早就算过。

前方，十九岁的帝国新兵汤姆抱着一只封蜡邮袋，努力装作不冷。他被派去灰桥驻营报到，军靴还是新的。每走几十步，他就回头看一眼北方，像在等家乡从雨里追上来。

玛拉说：“斥候，前面安不安生？”

### 选择

1. **“我去看路。车队停在有树的地方，别点灯。”**
   - 〔效果〕`rel.tom +1`（你让汤姆留在车边）
   - → `E-PRO-02`

2. **“让汤姆跟我去。他迟早得学会看路。”**
   - 汤姆一愣，随即把邮袋扎紧：“我不会拖后腿。”
   - 〔效果〕获得一次侦察帮助；若之后保护汤姆，关系额外提升
   - → `E-PRO-02`

3. **“多给两张券，我替你保证安全。”**
   - 【玛拉】“保证是贵族说的话。斥候只能保证自己看见了什么。”
   - 〔检定：CHA，DC 13〕
     - 成功：玛拉同意到镇后加两张券，但要求你先承担货损。`promised_bonus = true`
     - 失败：她把账本收进怀里。“照原价干活，或者现在走。”`rel.mara -1`
   - → `E-PRO-02`

4. **“路从来没安生过。真想活着，就把最贵的货告诉我。”**
   - 玛拉盯你几秒，掀开脚边一角油布。下面是一只铅皮包边的小木匣，锁孔被蜡封死。
   - 【玛拉】“客人只让我送进黑砧矿区。别问里面是什么。”
   - 〔效果〕`knows_lead_coffer = true`
   - → `E-PRO-02`

## E-PRO-02 被踩弯的蓟草

【旁白】离开车辙三十步，雨声忽然变轻。不是雨小了，是林子太安静。水顺着山毛榉叶尖滴落，灌木底下没有鸟，也没有被惊起的小兽。

你蹲下去。路边一丛蓟草向北弯着，根部却沾了南侧坡地的白灰。有人从坡上搬过石头，又把脚印扫乱。泥里还有一小片黑色鳞粉，像从烧焦的鱼皮上刮下来的。

【内心】父亲离家的那天也下雨。你十五岁，站在屋檐下，看见带队的军士在马鞍旁系了一根白绳。很多年以后你才知道，那是收拢临时征兵用的记号。那天你什么也没问。

### 选择

1. **检查坡顶与道路夹角。**
   - 〔检定：INS，DC 13；独自侦察时无修正，汤姆同行时 `+1`〕
   - 成功：发现两处弩位、一根截马绳和一条向河沟撤离的小径。`ambush_read = true`
   - 失败：你找到截马绳，却没看见藏在枯树后的第二名弩手。`ambush_partial = true`
   - → `E-PRO-03`

2. **立刻回去让车队调头。**
   - 你没有证据，但经验先于证据活下来。
   - 〔效果〕`defiance +1`；商队开始掉头，伏击者提前发动；全队获得掩体但最后一辆车被卡住
   - → `E-PRO-03`

3. **沿撤离小径反向摸上去。** 〔仅 `ambush_read` 或 DEX 修正至少 +2〕
   - 你在灌木后看到六个人：三个穿矿工皮衣，两个披旧军斗篷，还有一个蒙着下半张脸。蒙面人手里拿着一张画得粗糙的铅皮木匣图样。
   - 〔效果〕`knows_target_is_coffer = true`；下一场可先制
   - → `E-PRO-03`

4. **让汤姆先回报，自己留下看清他们。** 〔仅汤姆同行〕
   - 汤姆低声问：“你会回来吧？”
   - **“会。”** → `rel.tom +1`，你独自获得先制。
   - **“别等我。让他们活着到镇。”** → `sacrifice +1`，汤姆记住这句话；你进入危险位置，伏击开始时受 2 点伤害。
   - → `E-PRO-03`

## E-PRO-03 石落

【旁白】第一块石头不是冲人来的。它从坡上滚落，撞断车轴，把队伍切成前后两截。紧接着弩弦响了。最前面的驮马跪进泥里，玛拉被甩下车辕。有人从林子里喊：“只拿匣子！不想死的趴下！”

你能看见三件同时发生的事：玛拉的小儿子彼得被压在翻倒的车板下；两名袭击者扑向铅皮木匣；汤姆在路中央愣住，手里还死死抓着帝国邮袋。

### 选择

1. **先救彼得。**
   - 〔检定：STR，DC 13〕
   - 成功：你抬起车板，玛拉把孩子拖走。`saved_peter = true; mercy +1; rel.mara +2`
   - 失败：车板压住你的手，失去 3 HP；彼得被玛拉与车夫合力救出。`saved_peter = true; rel.mara +1`
   - 代价：袭击者带走木匣。`coffer_stolen = true`
   - → `E-PRO-04`

2. **扑向木匣。**
   - 〔检定：DEX，DC 13；`ambush_read` 时有优势〕
   - 成功：你踢开匣子，用车轮作掩体。进入一次短战斗，对手为两名劫匪；胜利后 `coffer_saved = true`。
   - 失败：弩箭擦过肋下，失去 4 HP；木匣被夺走。你扯下其中一人的铜扣，上面刻着疤脸。`toren_badge = true; coffer_stolen = true`
   - 代价：彼得腿部重伤。`peter_injured = true; rel.mara -1`
   - → `E-PRO-04`

3. **把汤姆撞进沟里，自己朝弩手还击。**
   - 〔检定：DEX，DC 13〕
   - 成功：弩手受伤逃走；汤姆活下。`tom_alive = true; rel.tom +2`
   - 失败：你仍救下汤姆，但手弩被落石砸坏。`hand_crossbow_broken = true; rel.tom +2`
   - 代价：木匣被夺，彼得受伤。`coffer_stolen = true; peter_injured = true`
   - → `E-PRO-04`

4. **大喊：“匣子给你们，留一匹马和药！”**
   - 〔检定：CHA，DC 16；若 `knows_target_is_coffer`，DC 13〕
   - 成功：蒙面人接受交易。袭击者取匣离开，丢下一包止血粉。无人重伤。`coffer_stolen = true; medicine_pack = true; mercy +1`
   - 失败：他们照拿匣子，并趁你暴露位置射击。失去 3 HP；汤姆或彼得中伤，优先伤害关系较低者。`coffer_stolen = true; alarm_town +1`
   - → `E-PRO-04`

5. **故意指出错误的货车，然后从撤离路包抄。** 〔仅 `ambush_read`〕
   - 〔检定：CHA 或 DEX，DC 13〕
   - 成功：袭击者扑错方向。你制服一人并保住木匣，但彼得轻伤。`coffer_saved = true; prisoner = reed`
   - 失败：对方识破，你被围住。可以丢 8 张随身票据换脱身，或打一场困难战斗。无论哪种，木匣被夺。
   - → `E-PRO-04`

## E-PRO-04 没有名字的旅人

【旁白】打斗只持续了几分钟，雨却把它洗得像很久以前。活着的人把伤者拖到树下，死者留在路上。你清点脚印时，在断轴后发现一名不属于商队也不属于袭击者的旅人。

他穿灰色长衣，胸口没有外伤，嘴角却全是黑血。一只手伸向灰桥方向，另一只手压着衣襟。衣襟里有一枚暗淡的铁戒指，内圈刻着你不认识的细字。

当你的指尖碰到戒指，世界里所有声音同时退远。

【内心】雨。屋檐。父亲背对着你，把一只磨破的手套塞进腰带。他没有回头。母亲在门后咬着布，不让自己哭出声。你知道下一刻会发生什么：你会说“我来照顾她们”，像一个不懂承诺重量的孩子。

可这一次，记忆里的父亲回过头来。

【父亲的声音】“南边。把我带到南边。”

你猛地抽回手。戒指已经套在你的右手食指上。它尺寸正好。

### 选择

1. **拔下戒指，丢进泥里。**
   - 它落地，没有声响。你走出三步，右手忽然一沉；戒指又在原处，沾着并不存在的温热雨水。
   - 〔效果〕`defiance +1; fragment_pressure +1`
   - 【内心】至少你确认了一件事：不是你舍不得。
   - → `E-PRO-05`

2. **握住戒指，追问“你是谁”。**
   - 回答你的不是语言，而是彼此冲突的片段：六声错开的城钟、一条向西钻入山腹的矿车轨、白袍人把银灰倒进碗里、陌生双手剪断一根发光的细线。它们更像四种可能，不像一条道路。
   - 〔效果〕`cure_rumors = [bell, mine, church, sever]; fragment_used +1; fragment_pressure +1`
   - 你鼻腔流血，失去 1 HP。
   - → `E-PRO-05`

3. **让自己把那场告别重新看完。**
   - 父亲走进雨里。没有神秘回头，没有留下遗言。他只是害怕，走得很快。你想起自己当晚把他的木碗摔碎，又撒谎说是莉莉碰的。
   - 〔效果〕`fragment_resisted +1; sacrifice +1`；你主动放弃了“父亲临走从容勇敢”的美化记忆
   - 获得状态 `memory_anchor_honest`，后续一次精神检定自动成功。
   - → `E-PRO-05`

4. **搜查尸体，先弄清这东西值多少钱。**
   - 旅人身上有半张矿道图、一枚被刮去徽记的学院章，以及一张写着“伊索尔，白鸦旅店，钟响前”的纸。
   - 〔效果〕获得 `half_mine_map`、`ysolde_note`；`corruption +1` 仅在拿走死者全部 6 张票据时增加
   - → `E-PRO-05`

## E-PRO-05 清点代价

本节点按上一场结果播放一个开头。

### 若救下彼得

【玛拉】“钱照付。”她跪在儿子身边，手在发抖，语气却像钉子，“货丢了算我的。你把人从板子底下抬出来，这才是我雇你的事。”

她当场给你二十八张票据。若木匣也保住，则另加四张；若先前谈妥奖金，再加两张。

### 若保货而彼得受伤

【玛拉】“客人会满意。”她替彼得缠布时没有看你，“你也会拿到钱。别指望我谢你。”

你得到三十二张票据，但 `rel.mara -1`。你可以留下 6 张支付彼得的医药费：`sacrifice +1; rel.mara +1`。

### 若汤姆获救

汤姆把邮袋抱在怀里，牙齿打战。

【汤姆】“我刚才什么都没做。”

- **“你活下来了。先学会这个。”** → `rel.tom +1`。
- **“你欠我一条命。进城后替我办一张离境文书。”** → `rel.tom -1; tom_owes_favor = true`。
- **“把你看到的疤脸徽记写进报告。”** → 若有徽记或俘虏，`harlan_evidence = true`。

### 若抓到俘虏里德

里德是黑砧矿区的装料工，左耳缺了一角。他承认托伦的人只要铅皮匣，不知匣内为何物。

【里德】“我们三个月没拿工钱。疤脸说干完这票，矿井里的欠账一笔勾销。你觉得我该信谁，帝国吗？”

- **交给帝国。** → `prisoner_to_empire = true; mercy -1`；里德后续可能死在押送中。
- **割断绳索，拿走他的徽记。** → `mercy +1; rel.toren -1`；他会在矿区为你说一句话。
- **逼问矿区暗路。** 〔INS，DC 13〕成功得到 `mine_drain_route`；失败时他给出会经过塌方区的半真路线。
- **杀了他，免得泄露行踪。** → `cruelty +1; rel.tom -2`（若汤姆在场）；获得徽记但矿工后来知道此事。

→ `E-PRO-06`

## E-PRO-06 莉莉的信

【旁白】汤姆的邮袋在混乱中裂了一角。一封没有军蜡、只用面粉浆封口的短信从夹层滑出来。收信人是你，字迹向右歪，是莉莉写得太快时的样子。

> 哥：
>
> 妈的咳嗽又重了，但她不让我写。哈兰的人说明天起封南门，只有军属、商会担保或离境文书能走。杂货铺老板不肯把你存的券给我，说必须本人签字。还有，昨晚有人来问爸的名字，戴灰手套，像是知道他怎么死的。
>
> 你若赶不回来，我会自己想办法。别为赶路死在外面。

最后一句被水洇开了。

### 选择

1. **把信折好，放在木梳旁。**
   - 〔效果〕`family_warned = false; private_goal = secure_exit_writ`
   - 【内心】她说会自己想办法。这正是最让你害怕的一句。

2. **请汤姆先入城，把口信带给莉莉。** 〔仅汤姆可行动〕
   - 若 `rel.tom >= 1`，他答应并从军人侧门入城。`family_warned = true; rel.tom +1`。
   - 若关系较低，他要求你免掉救命人情或给 2 张票据。接受则同上。

3. **问玛拉借商会担保。** 〔`rel.mara >= 1`〕
   - 她撕下账本副页，写明你是护卫。此担保能让两人出城，但不能带你。`merchant_guarantee = true`。
   - 【玛拉】“别把它卖了。纸只救写在上面的人。”

4. **先检查“灰手套”是否与死者有关。**
   - 学院章背面有一道被刻花的七芒星，与信封角落不小心留下的炭印相似。
   - 〔检定：INS，DC 13〕成功：`shadow_named_hint = true`；你判断来访者故意让莉莉看见手套，像在把你引回镇。

→ `E-PRO-07`

## E-PRO-07 城门外的最后一里

【旁白】车队重新上路时已经入夜。灰桥木墙终于变大，城门却关了一半。墙外挤着十几辆不准进城的农车。守门兵用长矛把人群隔开，公告板上新钉着一张封锁令：因黑砧矿区发生“煽动与失窃”，南北道路自午夜起军事管制。

戒指在手指上轻轻收紧。不是疼，更像有人牵住了你。

一名披灰袍的旅者站在排队的人群末尾。他没有被雨打湿。你眨眼时，他已站到公告板旁。

【灰袍人】“你父亲走南门时，也以为把家留在身后就能保住他们。”

### 选择

1. **追上去抓住他。**
   - 你拨开人群，抓到的却是一件挂在木钉上的空雨衣。守门兵喝令你退后。
   - 〔效果〕`fragment_pressure +1; alarm_town +1`

2. **问：“你知道我父亲怎么死的？”**
   - 【灰袍人】“我知道他最后记得什么。别把戒指丢得太远——你先失去的会是他的脸。”
   - 他融进一辆经过的黑篷车影里。`shadow_offer = true`。这句话既像威胁，也像关于离体症状的警告，暂不标记目的地。

3. **闭眼数出五件此刻真实的东西。**
   - 泥水的冷，木梳的齿，肩带的勒痕，玛拉在骂守门兵，汤姆的邮袋有湿纸味。你再睁眼，灰袍人不见了。
   - 〔检定：WIL，DC 13〕成功 `fragment_resisted +1; defiance +1`；失败 `fragment_pressure +1`，但不增加警戒。

4. **顺着牵引看它要你注意什么。**
   - 你看见黑篷车底滴下白灰，和伏击处一样。车轴刻着红牡丹的花纹，却被人用泥故意抹过。
   - 〔效果〕`fragment_used +1; mira_cart_hint = true`

→ `E-PRO-08`

## E-PRO-08 进入灰桥

守门兵要求说明身份与来意。

### 可用方式

- 出示玛拉的雇佣账页：无检定入城；若商队损失惨重，兵士会扣留玛拉问话，你可留下作证（`time +1; rel.mara +1`）或先走。
- 让汤姆以新兵身份担保：`rel.tom >= 1` 时入城并获得 `tom_barracks_access = true`。
- 出示疤脸徽记谎称矿区送信人：CHA DC 13；成功从货门进入，失败提高 `alarm_town` 并被搜走普通违禁品。
- 翻过北墙旧排水口：DEX DC 13；成功进入牲口巷，失败失去 3 HP并引来巡兵，仍可付 3 张票据脱身。
- 交 4 张票据：直接入城，守门兵不记录名字。

【旁白】门洞吞下你的身影。雨声被厚木门隔在背后，镇内的钟刚敲八下。街道比记忆里空，所有窗都关着。白鸦旅店的招牌在风里转动；东边礼拜堂亮着灯；南巷深处，红牡丹门前那盏红灯笼还没有熄。

戒指朝三个方向各牵了一下，最后指向脚下。

〔效果〕`time = max(time,1); resonance = 1`；按结果结算票据、伤势与物品。

→ `A1-TOWN-01`
