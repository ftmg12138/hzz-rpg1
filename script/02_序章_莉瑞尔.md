# 02 序章：莉瑞尔——被烧掉的人仍有影子

> 预计游玩 13—17 分钟。核心问题不是证明莉瑞尔无罪，而是让她决定是否愿意让别人知道她当年活下来的方式。

## L-PRO-01 苔冠哨所

〔进入〕选择莉瑞尔。

【旁白】苔冠哨所已经没有屋顶了。十年前的火烧黑了梁木，后来长出的苔把黑色盖成绿色，远看像一处安静的土丘。只有走近，才会看见门框上的刀痕、井沿里融化的银饰，以及那棵始终不再发芽的白桦。

你在白桦下站了很久，直到天开始下雨。

家庭账簿里缺失的第七码纸很可能还在旧宅。瓦伦花了半年才从一个醉酒的前军需官嘴里问出这件事。那页纸或许能说明母亲替谁保管古物，也可能只是一笔霉掉的粮食账。

废墟有三处可查：塌掉的起居室、父亲的地窖、哨所档案房。天黑前只够仔细搜两处。

### 选择

1. **先搜起居室。**
   - 在石灰下找到一只儿童木杯和半枚烧裂的发扣。
   - 〔检定：INS，DC 10〕成功发现壁炉砖被重新砌过，取得 `family_cache_key`。
   - 【内心】妹妹小时候只肯用这只杯子。你当年躲在地窖里，听见她在楼上叫你一次。只有一次。
   - → 返回地点选择。

2. **先去父亲的地窖。**
   - 门被从外面钉死，钉子比火灾新。若有钥匙，可打开侧锁；否则 DEX 或 STR DC 13。
   - 成功进入 `L-PRO-02`；失败也可进入，但手掌割伤，失去 2 HP且发出声响。

3. **先搜档案房。**
   - 找到帝国制式油封碎片、三张无法辨读的湿纸和一段被刮过的墙铭。
   - 〔检定：INS，DC 13〕成功取得 `imperial_oil_seal` 与铭文句子：“见证必须出于自愿。”`truth +1`
   - → 返回地点选择。

4. **在废墟外等，观察还有谁来。**
   - 你藏在断墙后。半小时后，一名穿旧矿工衣服的男人钻进档案房。他左手少两根指头，走路避开所有有焦骨的地方。
   - 〔效果〕`saw_scavenger = true; time +1`
   - → `L-PRO-03`

搜过两处或进入地窖后推进。

## L-PRO-02 银链

【旁白】地窖比记忆里矮。你曾在这里蜷缩一整夜，现在必须低头才能进去。木架早已腐烂，碎瓶踩在脚下发出细响。最里面那面墙还留着你用指甲抓出的痕迹。

墙缝里卡着一本烧焦的账簿。你自己的那本正缺这半边装订线。翻动时，一条极细的银链从书脊夹层滑下，挂坠只是一片无花纹的椭圆银片。

你认得它。母亲从不许任何人碰，却在哨所被攻破前一晚亲手塞进账簿。

银片贴上掌心，寒冷先沿手臂爬到肩，然后忽然变热。

地窖外有脚步。一个陌生男人低声咒骂，正用铁钩拨开门边的石块。银链在你掌中震动，你忽然非常清楚自己可以怎样让他放下戒心：把声音放软，让呼吸显得慌乱，让他相信你需要他。

那念头熟练得不像第一次出现。

### 选择

1. **把银链戴上，顺从这股直觉。**
   - 你靠近门边，声音里带上一点恰好的颤抖：“我被困住了。请帮帮我。”
   - 男人立刻丢下铁钩来搬石头，甚至没有先问你是谁。
   - 〔效果〕`fragment_used +1; corruption +1; fragment_pressure +1`；下一次对该人 CHA 检定有优势
   - → `L-PRO-03`

2. **咬住舌尖，用疼痛压下亲近冲动。**
   - 〔检定：WIL，DC 13〕成功 `fragment_resisted +1; defiance +1`；失败仍未使用魅惑，但获得 `shaken`，下一次 CHA 检定劣势。
   - → `L-PRO-03`

3. **利用冲动，但先给对方留一个拒绝的机会。**
   - 【莉瑞尔】“我在里面。我会带着一件你想要的东西出来，但你最好先告诉我你为谁做事。”
   - 这不是魅惑，只是交易。`defiance +1`；若对方撒谎，你下一次 INS 检定有优势。
   - → `L-PRO-03`

4. **把银链塞回账簿。**
   - 你合上书。片刻后，链子却从袖口滑进手腕，像早就戴在那里。
   - 〔效果〕`fragment_pressure +1`
   - 【内心】它想要的不是被携带。它想要被承认。
   - → `L-PRO-03`

## L-PRO-03 少指的男人

来者名叫布兰，五十岁上下，左手少了无名指与小指。他看到你后先看银链，再看你的脸。

【布兰】“你是赛拉的女儿。”

【莉瑞尔】“你认识我母亲？”

【布兰】“我认识她把门关上的样子。”

他承认自己当年是给帝国侦察队搬补给的民夫。袭击前，赛拉把一册名单和一件银饰交给某人；随后帝国军与戴无徽记面罩的人一起进入哨所。官方报告却写“兽人袭击”。布兰这些年替不同买家找那册名单，因为托伦承诺免掉他儿子在黑砧矿的债。

### 选择

1. **“把你知道的全说出来，我会替你儿子还债。”**
   - 需要 8 张票据作为定金；或 CHA DC 13 让他先信你。
   - 成功：布兰给出儿子工牌与当年军官名字“副尉科尔”。`bran_testimony = true; miners_contact = oswin`
   - 失败：他要求先看账页，你若拒绝则关系恶化。

2. **让银链替你说服他。** 〔始终可见，若已使用残片则标注“你知道怎样做”〕
   - 你触碰他的手腕，说出他最想听的话：“奥斯温今晚就能自由。”
   - 他把所有线索都交给你，甚至说出藏在灰桥仓库的帝国副本。
   - 〔效果〕`fragment_used +1; corruption +1; bran_testimony = true; warehouse_archive = true`
   - 后果：承诺若未履行，布兰会在矿区报警。

3. **“你替他们搬了油，又回来翻死人的家。别装成证人。”**
   - 布兰脸色发白：“我从没说自己是好人。”
   - 〔检定：INS，DC 13〕成功看出他对母亲关门一事另有隐瞒，解锁追问；失败使 `rel.miners -1`。
   - 追问后他承认：赛拉亲手封了地窖门，知道莉瑞尔藏在里面。她选择救一个女儿而没有敲响全哨警钟。`mother_chose_liriel = true`

4. **袭击他，夺走工牌和口供袋。**
   - 〔战斗或 DEX DC 13〕成功取得工牌、帝国油封与仓库编号；`cruelty +1; rel.miners -2`
   - 失败：布兰逃向灰桥示警；你取得他掉下的半张编号纸，但 `alarm_town +1`。

5. **放他走，不索要任何东西。**
   - 若你知道他儿子的名字，你可以说：“告诉奥斯温，今晚别下最深那层。”`mercy +1; workers_warned = true`。
   - 不警告则仅 `defiance +1`。

→ `L-PRO-04`

## L-PRO-04 账簿第七码

【旁白】烧焦的夹页在雨汽里慢慢展开。纸上不是古代咒文，而是母亲的日常账：盐两袋、箭羽三束、给人类商贩的路费。最下方多了一行用精灵旧体写的字。

> 将“饥渴”交给灰桥的见证者。不要让科尔找到第七声之下的门。若门被攻破，我会保住能活下来的那个，而不是最勇敢的那个。

在这句话下面，是你名字的首字母。

### 选择

1. **接受母亲选择了你，但不把它当成宽恕。**
   - 〔效果〕`memory_anchor_honest = true; sacrifice +1`
   - 【内心】被选择活下去，不等于此后每一天都必须证明自己值得。也不等于那一夜没有债。

2. **撕掉写有自己名字的部分。**
   - 〔效果〕失去完整书证，`family_evidence_damaged = true; defiance +1`
   - 你保留关于第七声的句子，但以后无法证明母亲的动机。

3. **把账页收好，决定只公开对自己有利的部分。**
   - 〔效果〕`corruption +1; selective_testimony = true`
   - 后续面对凯尔时可隐瞒母亲的选择。

4. **在原地读出名字与整句话。**
   - 雨落进地窖。布兰若在场，会低下头；你若独自一人，也至少听见了自己的声音。
   - 〔效果〕`defiance +1; fragment_pressure -1`

→ `L-PRO-05`

## L-PRO-05 凯尔的箭

【旁白】你离开废墟时，一支箭钉在前方白桦上。箭没有瞄你，尾羽却是苔冠旧式。

凯尔从断墙后走出来，银发被雨压在颊侧。他比十年前更瘦，也更像一把从鞘里拔了一半的刀。

【凯尔】“把链子放在地上。”

他认出你，也认出母亲的银饰。他追踪布兰和托伦的买家来到这里，相信银链是导致哨所覆灭的诱饵。

### 选择

1. **照做，但用脚踩住链子。**
   - 【莉瑞尔】“我可以不拿它。你也别想拿。”
   - `rel.kael +1; defiance +1`。凯尔同意先听你解释。

2. **把完整账页递给他。** 〔账页未损坏〕
   - 凯尔读到你名字时停了很久。
   - 【凯尔】“赛拉救了你。”
   - 【莉瑞尔】“她也没有救他们。”
   - `rel.kael +2; truth +1`。他承认当年自己在外巡逻，回援途中因害怕帝国人数太多而等了半个时辰。他也不是无罪的幸存者。

3. **隐瞒母亲选择你的句子。** 〔`selective_testimony`〕
   - 〔检定：CHA，DC 13〕成功 `rel.kael +1`，但记录 `lied_to_kael = true`；失败关系降至 -1，凯尔仍不揭穿，只说：“你还是先替别人决定他们该知道什么。”

4. **用银链令他放下弓。**
   - 〔检定：CHA，DC 13，残片给予优势〕
   - 成功：他放弓的瞬间意识到自己被影响，`rel.kael -2; corruption +1; fragment_used +1`。
   - 失败：箭擦伤肩，失去 3 HP；凯尔切断银链，但挂坠随后出现在你颈后。`fragment_pressure +1`

5. **“你若想审判我，就先承认你那晚也没回来。”** 〔知道凯尔旧事或 INS 修正 +2〕
   - 凯尔沉默。雨从弓尖一滴一滴落下。
   - `rel.kael +1`，解锁 `kael_confession`，但若语气选择嘲讽则 `cruelty +1`。

无论结果，凯尔告诉你：托伦的人今晚会把一只铅皮匣送入黑砧；灰桥的前学院学者伊索尔正在白鸦旅店等一个已死的信使。

→ `L-PRO-06`

## L-PRO-06 路边的求救

【旁白】通往灰桥的小路经过一座废弃炭棚。里面传出压低的哭声。一个十六七岁的人类女孩被两名穿便衣的男人按在墙边。他们搜她的包，反复问：“米拉把名单藏在哪？”

凯尔若同行，手已经搭上弓弦。银链则贴着你的皮肤发热。那女孩抬头看见你，恐惧里立刻生出一种近乎不讲理的信任。

### 选择

1. **现身制止。**
   - 可威吓（CHA DC 13）、欺骗称帝国巡查（有油封自动成功）或战斗。
   - 成功救下女孩妮芙。她是红牡丹的跑腿人，携带矿工家属名单。`saved_neve = true; rel.mira +1; mercy +1`
   - 失败仍能赶走一人，但另一人割伤妮芙并带走半份名单。你失去 2 HP或消耗治疗物。

2. **让凯尔射击。** 〔凯尔同行〕
   - **要求只伤手。** DEX/关系检定成功二人逃走，无人死亡；失败一人被射穿喉咙。凯尔说：“你要我动手，就别假装箭会听你的良心。”
   - **允许杀死。** `cruelty +1; rel.kael +1`，妮芙对你畏惧，`rel.mira` 不增加。

3. **用银链引开其中一人，再偷袭另一个。**
   - 自动救人，`fragment_used +1; corruption +1`。被你引开的男人会在镇里执着寻找你，产生随机事件 `R-DES-06`。

4. **绕过去。**
   - `defiance +1` 仅表示拒绝被事件牵住，不是善行。妮芙的哭声在身后停止。
   - 后续 `neve_captured = true; rel.mira -1`，托伦获得名单。

5. **等他们搜完，再从女孩处买情报。**
   - `cruelty +1; corruption +1`。你获得名单去向，但妮芙会认出你，米拉后续拒绝正常交易。

→ `L-PRO-07`

## L-PRO-07 欲望的名字

在离城一里处触发第一次完整侵扰。

【旁白】雨停了。凯尔或妮芙走在前方，湿衣贴在肩背。没有同伴时，路旁旅舍的窗里透出暖光，有人正在唱一首你听不懂的人类情歌。

银链骤然收紧。热意从腕间沉进小腹，再往更私密处涌。你想被手掌按住腰，想被进入，想用交合确认自己不是地窖里那个屏住呼吸的影子。欲望先是身体里的热，随后变成更难承认的东西：如果别人真正渴望你，你就暂时不用判断自己值不值得活。

### 选择

1. **向愿意的人提出亲近，并允许对方真实回答。**
   - 若凯尔在场且关系至少 +1：他回答“现在不行。但你可以走近一点。”肩贴肩、指节相扣；`rel.kael +1; fragment_pressure -1`。
   - 若妮芙在场：她握住你的手，说可以陪你走，不是今晚就得脱衣服；`rel.mira +1`。
   - 无同伴：你进入旅舍，与愿意的陌生人发生双方自愿的性行为（可写身体接触与高潮，不可写强迫）；`time +1; fragment_pressure -1`，失去 3 张票据。此选择本身不增加腐化。

2. **利用银链确保对方不会拒绝。**
   - 对方眼神空白、身体仍在迎合——不是自愿。画面切断。
   - `fragment_used +1; corruption +2; fragment_pressure -1`；凯尔在场会立刻离队并 `rel.kael -3`。

3. **把冲动转成坦白。**
   - 你告诉同行者：“我现在很想让任何人证明我不是多余的。这不是请求，只是事实。”
   - `fragment_resisted +1; defiance +1`。若关系非负，同伴也说出一个恐惧，解锁后续羁绊对话。

4. **独自压下去，拒绝让任何人看见。**
   - 〔WIL，DC 13〕成功 `fragment_resisted +1`；失败获得 `shaken` 与 `fragment_pressure +1`。不论成败，你没有伤害别人。

5. **用刀尖在银片上刻一道痕，提醒它这具身体是谁的。**
   - 失去 1 HP；`defiance +1; fragment_pressure -1`。银片上的划痕会在终幕成为识别“饥渴残片”的证据。

→ `L-PRO-08`

## L-PRO-08 灰桥盘问

城门只开一人宽。卫兵要求精灵与流民登记来源。

### 可用方式

- 出示帝国油封，自称替档案处送旧证物：CHA DC 13；成功获 `warehouse_access_hint`，失败油封被扣但仍可排队入城。
- 由妮芙领进红牡丹的送货侧门：`saved_neve` 时自动成功，并获得 `mira_safehouse_hint`。
- 与凯尔从旧猎道翻墙：DEX DC 13；成功不留姓名，失败触发短追逐、失去 2 HP且 `alarm_town +1`。
- 正常登记“苔冠哨所幸存者”：无需检定，但名字会送到哈兰桌上。`harlan_knows_liriel = true`。
- 魅惑守门兵：自动入城；`fragment_used +1; corruption +1`，守门兵随后擅离岗位找你，引发纪律处罚和一条后续新闻。

→ `L-PRO-09`

## L-PRO-09 旧名字进城

【旁白】灰桥比记忆里拥挤，也比传闻里安静。精灵面孔使几扇窗后的目光停在你身上。远处的礼拜堂钟敲八下，银链随每一下震动。白鸦旅店、礼拜堂与南巷红灯在雨后水洼里各自留下倒影。

凯尔若同行，在巷口停住。

【凯尔】“进了城，我们可能想要不同的东西。我要让当年的名字见光。你也许只想知道他们为什么死。”

【莉瑞尔】“还有区别吗？”

【凯尔】“见光会烧到活人。”

银链把你的注意力拉向地下。那里有另一种饥饿，古老、耐心，仿佛等了十年才等到你回头。

〔效果〕`time = max(time,1); resonance = 1`。

→ `A1-TOWN-01`
