# 03 序章：索林——一笔应该简单的订单

> 预计游玩 12—16 分钟。核心矛盾是“守约”究竟是服从纸面，还是对承担后果的人负责。

## T-PRO-01 石松工棚

〔进入〕选择索林。

【旁白】订单上写得很清楚：四十枚帝国制式甲扣、十二个车轴箍、三把修复好的矿镐，日落前送抵石松工棚，由军需代理科德验货盖印。没有龙，没有古墓，也没有命运。只是一笔足以让父亲在同业面前少皱两个月眉头的普通生意。

科德却不在。

工棚门口站着六名托伦的私兵，胸前缝着粗糙的红色疤纹。领头人说科德已把订单转给黑砧矿区，叫你连货带车继续向南。新单据上的价钱少了三成，交付期限则从日落改成午夜。

女商人赫尔嘉靠在你的货车旁嗑坚果。她是格罗姆的远亲，也是这片路上最不愿白白浪费一句同情的人。

【赫尔嘉】“盖章是真的，墨也是新的。至于科德是在桌边盖的，还是被按着手盖的，那不归商人管。”

### 选择

1. **拒绝转单，要求见科德本人。**
   - 私兵冷笑：“矮子，纸认得你的货，不认得你的脾气。”
   - 〔效果〕`rel.toren -1; defiance +1`
   - → `T-PRO-02`

2. **检查单据、铆钉箱和工棚痕迹。**
   - 〔检定：INS，DC 13〕成功发现印章真、签名假，地上有拖拽血迹；`forged_transfer = true`。
   - 失败只能判断纸张来自帝国军需库；下一次与私兵交涉无优势。
   - → `T-PRO-02`

3. **接受减价，但要求当场付一半。**
   - 〔检定：CHA，DC 13〕成功得到 12 张票据与矿区通行木牌，`toren_bargain = true`；失败只得到木牌，对方保证“到矿里一起结”。
   - → `T-PRO-02`

4. **问赫尔嘉愿不愿买下整批货。**
   - 她开出原价六成，现付，不问来源。
   - **卖。** → 得 18 张票据，失去订单货物，`private_goal` 仍未完成；赫尔嘉提供灰桥仓储位。
   - **拒绝。** → `rel.helga +1`，她说“至少你知道自己的固执值多少钱”。
   - → `T-PRO-02`

## T-PRO-02 不该在剑里的表

私兵把一柄弯曲的古剑扔在工作台上，要求你“证明自己真是工匠”，把护手拆下重铆。剑身看似精灵式，重量却集中在柄内。

【旁白】你把剑固定，轻敲第三下，柄芯裂开。一只拇指大小的黄铜怀表掉在毡布上。没有表针，表盖刻着四个相套的圆。它明明没有上弦，却发出缓慢的咔哒声。

领头私兵伸手：“交出来。”

怀表在他开口的瞬间骤然变热。你突然厌恶这只伸来的手，厌恶假签名，厌恶父亲每次说“生意上忍一忍”，厌恶所有人把拖延和抢夺包装成规矩。工作锤已经在你手里。只要一下，他的手骨就会像劣铁一样开裂。

### 选择

1. **砸下去。**
   - 〔检定：STR，DC 10〕成功必然砸断对方两根指骨，引发战斗；`fragment_used +1; corruption +1; rel.toren -2`。
   - 若战斗胜利，你可逼问科德下落；失败则被缴货并关进工棚储藏间，转 `T-PRO-04B`。

2. **把锤子砸在工作台上。**
   - 桌面裂开，所有人退了一步。
   - 〔检定：WIL，DC 13〕成功把怒气导向威慑，`fragment_resisted +1; defiance +1`，可继续谈判；失败仍砸桌，但怀表压力 +1，私兵认为你虚张声势。
   - → `T-PRO-03`

3. **将怀表攥进掌心，冷静询价。**
   - 【索林】“剑是你们的，剑里掉出来的东西算新发现。想拿，报价。”
   - 私兵开 5 张票据。接受时怀表会在交手一刻重新出现在你衣袋；你仍得钱，但 `fragment_pressure +1`。
   - 拒绝则 `rel.helga +1`，赫尔嘉开始认真观察怀表。
   - → `T-PRO-03`

4. **让赫尔嘉鉴定。**
   - 她只看一眼便不再嗑坚果。
   - 【赫尔嘉】“这不是表。至少，不是拿来看时辰的。把它包起来，去找格罗姆。现在。”
   - `ancient_craft_hint = true; rel.helga +1`
   - → `T-PRO-03`

5. **假装它只是废件，顺手扫进零件袋。**
   - 〔检定：DEX，DC 13〕成功无人察觉；失败领头人看见动作却没拆穿，暗中派人跟踪。`followed_to_town = true`
   - → `T-PRO-03`

## T-PRO-03 科德在地窖

若此前发现血迹或坚持见人，可找到后门地窖；否则赫尔嘉会以“我的货秤落里面了”为由引开一名守卫，让你听见地板下的撞击声。

科德被绑在地窖暖气管旁，额角破裂。他承认私兵逼他盖了转运章，因为托伦急需甲扣修补矿井升降架，而不是军用铠甲。帝国已经冻结托伦的账，正规采购走不通。

【科德】“如果升降架断了，下面四十多个人上不来。但我按原合同收货，哈兰明早就会扣走这些东西。你问我该给谁？我也想知道。”

### 选择

1. **救出科德，坚持按原合同验收。**
   - 需要击倒或骗走守卫。成功取得合法交货印：`private_goal_secured = true; delivery_seal = true`。
   - 后果：货物会被帝国暂扣，矿井升降架无人修。`workers_warned = false; rel.toren -1`

2. **让科德盖原单，再把甲扣送矿区。**
   - 科德迟疑后照做：“这等于我替你我各撒一次谎。”
   - `private_goal_secured = true; miners_supplied = true; corruption +1`。这是善意造假，腐化记录的是手段而非道德审判。

3. **撕毁两份单据，只救人。**
   - `sacrifice +1; private_goal_abandoned = true; rel.helga +1`。科德提供托伦仓库的路条作为补偿。

4. **把科德留给私兵，换取高价与正式矿区印。**
   - `toren_bargain = true; cruelty +1; private_goal_secured = true`。私兵付 18 张票据并带走科德。
   - 科德后续出现在矿区囚牢，关系为 -2。

5. **先修升降架关键甲扣，只交能救命的一半。**
   - 〔工匠检定：STR 或 INS，DC 13〕成功把十二枚普通甲扣重锻成八枚承重扣，获得 `reinforced_lift_parts = true`，剩余货仍可部分验收。
   - 失败耗坏四枚材料，但知道旧件的问题，后续维修 DC 降低。

→ `T-PRO-04`

## T-PRO-04 工棚失火

【旁白】决定刚做出，外面便传来玻璃破裂声。火油从窗缝泼进工棚。有人不想让科德、假单据或那柄古剑活着抵达灰桥。

火先舔上货车油布。后门被从外面插住。赫尔嘉咳嗽着指向三处：科德还在地窖；装甲扣的木箱已经起火；靠墙的账柜里有工棚近半年的来货记录。

你最多能完整保住两项。若受伤或此前战斗失败，只能保一项。

### 选择组合

- **救科德。** `kord_alive = true; mercy +1`。需要占一个行动。
- **抢出甲扣箱。** `miners_supplied = true`。索林用湿毡裹箱，失去 2 HP。
- **抢出账柜。** `workshop_ledger = true`，其中有铅皮木匣和古剑都来自黑砧第四层的记录。
- **先开后门让所有人逃，再看能拿什么。** STR DC 13；成功额外获得一个行动，失败失去 3 HP且仍只保一项。
- **追纵火者。** 牺牲以上一项，抓到戴灰手套的人；他被抓时化成一件空斗篷，留下七芒星铜片。`shadow_named_hint = true`

若科德死亡而玩家已有交货印，印仍有效，但结局会写明这份合同由死人担保。

→ `T-PRO-05`

## T-PRO-04B 储藏间

〔仅战斗失败〕

【旁白】你醒来时嘴里有铁味，双手被自己的捆箱绳绑住。怀表在胸前咔哒作响，每一下都像锤子敲在牙根。门外两个私兵争论是把你送矿里干活，还是就地埋掉。

### 选择

1. **借怒意挣断绳索。** STR DC 13，残片可提供优势；使用则 `fragment_used +1; corruption +1`。成功夺回旧锤，失败失去 3 HP后赫尔嘉从外面割断门闩。
2. **观察货架找工具。** INS DC 13；成功用薄锯片脱困并取得一瓶火油。失败耗时，工棚先起火，只能救一项。
3. **假装愿意替托伦工作。** CHA DC 13；成功获得矿区木牌并被松绑，`toren_bargain = true`；失败被拖出时工棚起火，趁乱逃脱。

→ `T-PRO-04`

## T-PRO-05 第一次完整发作

【旁白】火势被雨压低后，幸存者沿南路走向灰桥。赫尔嘉推着剩下的车，车轮每转一圈都发出尖叫。她终于忍不住说：“你父亲接这单时就该知道边境的钱脏。现在摆出一张受骗的脸，没有用。”

怀表咔哒一声。

你忽然想砸烂那只坏轮子，砸烂假印，砸烂赫尔嘉永远正确的语气。力量像热铁灌进双臂。只要开始破坏，世界至少会有一件事按你的意愿改变形状。

### 选择

1. **砸烂货车，把还能用的铁件一件件捡出来。**
   - 这不是对人施暴。你失去车与一个储物位，但获得 `salvaged_iron`，后续修誓环自动成功一次。
   - `fragment_used +1; fragment_pressure -1`。

2. **对赫尔嘉吼出所有不满。**
   - 她听完，把最后一颗坚果塞进嘴里。
   - 【赫尔嘉】“很好。现在告诉我哪些是我的错，哪些只是你终于肯承认自己害怕。”
   - 〔WIL，DC 13〕成功 `fragment_resisted +1; rel.helga +1`；失败说出对格罗姆与父亲的怨，`rel.helga -1`，但压力仍降低。

3. **找一块无人的石壁狠狠干活。**
   - 你用旧锤把一根弯轴敲直，直到手掌裂开。失去 2 HP，获得 `straightened_axle`；`defiance +1; fragment_pressure -1`。

4. **把怒气对准一名被绑的纵火者或私兵。** 〔有俘虏时〕
   - 你可以打到他开口，也可以打到他再也不开口。
   - **停在开口时。** `cruelty +1`，取得排水渠路线。
   - **不停。** `cruelty +2; corruption +1; rel.helga -2`，取得路线与托伦口令，但俘虏死亡。

5. **打开怀表，研究声音来源。**
   - 表内没有齿轮，只有一圈极小的符文，随你的心跳亮灭。
   - 〔INS，DC 13；工匠背景 +1〕成功 `truth +1; ancient_craft_hint = true`；失败被震得耳鸣，下一次察觉检定劣势。

→ `T-PRO-06`

## T-PRO-06 格罗姆的旧记号

工作棚账页或古剑护手内侧都有同一个工匠记号：断开的砧。赫尔嘉确认那是格罗姆年轻时使用、后来亲手废弃的签名。

【赫尔嘉】“他住灰桥钟楼后面。你若去问，别拿‘为了家族’开头。他听过太多人拿家族当锤柄。”

若没有账页与古剑证据，怀表表盖在雨中自行浮出同样记号。

### 选择

1. **承诺只请格罗姆鉴定，不让他锻造武器。** → `gromm_approach_honest = true; rel.helga +1`。
2. **打算用师父的名义压他。** → `gromm_approach_pride = true`，后续初始关系 -1。
3. **先去黑砧交货，不找格罗姆。** → 获得矿区直接入口，但错过镇内最早的调律信息。
4. **问赫尔嘉是否早就知道这批货有问题。** INS DC 13：成功她承认自己受伊索尔委托盯着古剑，`rel.helga -1; ysolde_note = true`；失败她只说“怀疑不是知道”。

→ `T-PRO-07`

## T-PRO-07 城门与坏掉的车

【旁白】抵达灰桥时，城门正因矿区骚乱提前关闭。你的车若仍在，守兵要求开箱；若车已拆，你背着铁件，看起来更像逃难铁匠。

### 可用方式

- 出示合法交货印：直接入城，并可把货存在军需仓；若科德死亡，守兵会问印从何来，CHA DC 13。
- 出示矿区转运木牌：从货门进入，`rel.toren +1`，名字被记在托伦名单。
- 让赫尔嘉担保：关系至少 0 时可进入，但需把一件中型货物存进她仓库作为抵押。
- 当场修好城门绞盘：工匠检定 DC 13；成功免费入城并 `rel.harlan +1`，失败夹伤手失去 2 HP但守兵仍因你出力放行。
- 威胁砸门：STR DC 16；成功不是砸开，而是让守兵判断麻烦大于规费，支付 2 张票据入城；失败 `alarm_town +1`。

→ `T-PRO-08`

## T-PRO-08 钟声里的齿轮

【旁白】灰桥钟楼敲八点时，怀表与它错开半拍回应。城里的大钟响一次，怀表便在胸前响两次；到第八下，它已经快成一阵细密的虫鸣。

你看见三个去处：钟楼后格罗姆的小铺还亮着锻火；白鸦旅店门边贴着伊索尔招募搬运工的纸条；礼拜堂的灰衣修女正把伤员抬进去。南巷一辆黑篷车驶过，车底滴下来自黑砧的白色矿灰。

【内心】你只需要一个印章。进城，验货，回家。这句话到现在听来仍然合理，也因此显得可笑。

怀表的力量把你的手压向地面。地下某处，有一柄比山更大的锤子正在抬起。

〔效果〕`time = max(time,1); resonance = 1`。

→ `A1-TOWN-01`
