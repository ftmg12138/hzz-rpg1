# 00 开发约定：变量、检定与流程

## 1. 节点命名

节点采用 `阶段-地点-序号-变体`：

- `E-PRO-01`：艾德里克序章第 1 节。
- `L-PRO-01`：莉瑞尔序章第 1 节。
- `T-PRO-01`：索林序章第 1 节。
- `A1-TOWN-01`：第一幕灰桥镇公共节点。
- `A2-MINE-01A`：第二幕黑砧矿区入口节点。
- `A3-SHRINE-01`：第三幕初鸣庭公共节点。为避免开发迁移错误，节点前缀仍保留 `SHRINE`。
- `D-NPC-VALEN`：NPC 独立对话树。
- `R-MEM-01`：记忆残片随机侵扰。
- `C-04`：东仓冲突。
- `END-01`：结局。

节点只能有一个稳定入口 ID。文本变体在节点内部根据条件选择，不要复制整段节点制造维护分叉。

## 3. 全局状态

### 3.1 时间与推进

```text
time = 0                 # 0 黄昏，1 入夜，2 深夜，3 午夜，4 三更，5 四更，6 黎明
resonance = 0            # 0-6，共鸣压力
truth = 0                # 0-4，长誓钟真相层级
alarm_town = 0           # 0-3，镇内警戒
alarm_mine = 0           # 0-3，矿区警戒
city_actions = 0         # 雾钟城深入行动次数
city_rep = 0             # -3 至 +5，城市公共声望
curse_stage = 1          # 1-5，个人回声病恶化层级
sanctuary_clues = 0      # 0-3，初鸣庭定位线索类别数；稳定键保留
curse_transferred = false
anchor_severed = false
```

- 主线场景结束通常 `time +1`；短对话不耗时，明确标注“耗时”的可选调查才增加。
- 当 `time >= 6` 或 `resonance >= 6`，只在玩家已进入初鸣庭时转入 `A3-SHRINE-07-LATE`；仍在城市时触发 `curse_stage` 或城市共鸣危机，玩家可以选择静默署、个人治疗、强引入口或撤离。
- 共鸣不会因为原地等待而降低。治疗、沉沦和反复交易不能免费绕过倒计时。

### 3.2 倾向而非阵营

```text
mercy = 0                # -3 至 +5；残害无辜降低，承担风险救人提高
cruelty = 0              # 0 至 5；与 mercy 可同时非零，记录做过什么而非贴标签
sacrifice = 0            # 0 至 5；必须实际失去资源、机会、身体或关系
corruption = 0           # 0 至 6；主动借残片满足私欲或支配他人
defiance = 0             # 0 至 5；抵抗牵引，不等同善良
```

不要把某个选项直接标成“善良 +1”。只在结果中描述事实。结局按行为组合判断，例如高 `defiance` 加高 `cruelty` 是冷酷的自主者，不是英雄。

### 3.3 关系值

主要 NPC 关系范围 `-3…+3`：

```text
rel.valen / rel.eilyn / rel.gromm / rel.kael / rel.harlan / rel.mira
rel.skye / rel.toren / rel.ysolde / rel.helga / rel.tom
rel.alt_a / rel.alt_b     # 未选的两位主角
```

- `-3`：致命敌对；会主动破坏最终计划。
- `-2`：敌对；拒绝帮助并可能告密。
- `-1`：不信任；交易涨价、对话保留。
- `0`：陌生或公事公办。
- `+1`：认可；提供小帮助。
- `+2`：信任；透露私人信息或承担风险。
- `+3`：羁绊；愿意付出不可逆代价，但仍保留自身底线。

关系不是按钮货币。每个角色至少有一条不可用好感绕过的底线，见 `07`。

## 4. 钟骨数量、功能与压力

### 4.1 七枚总数与本篇四枚

长誓钟碎裂后共有七枚主钟骨。第一部只允许四枚进入场景与终幕，绝不能因为高真相、隐藏收集或完美路线凭空得到另外三枚。

| 序号 | 名称 | 原始盟约功能 | 失衡后的病理 | 第一部状态 |
|---:|---|---|---|---|
| 1 | 旧雨骨 | 保存双方实际说过的承诺 | 把回忆变成无法离开的现在 | 艾德里克戒指内，必然出现 |
| 2 | 饥月骨 | 让签约者承认自己真正所求 | 把愿望放大成占有与依赖 | 莉瑞尔银链内，必然出现 |
| 3 | 裂锤骨 | 保留拒绝、异议与中止权 | 把反抗放大成无差别愤怒 | 索林怀表内，必然出现 |
| 4 | 照心骨 | 显示决定由谁承担代价 | 把问责放大成无休止审判 | 黑砧深层，可取、封存或交给阵营 |
| 5 | 界碑骨 | 划定盟约影响的对象与土地 | 未知 | 不在雾钟城，仅作后续世界伏笔 |
| 6 | 远潮骨 | 把龙所见的百年后果译给短生种 | 未知 | 不在雾钟城，仅作后续世界伏笔 |
| 7 | 空座骨 | 为尚未出生的一代保留重新同意的位置 | 未知 | 不在雾钟城，仅作后续世界伏笔 |

本篇终幕调用的是四枚钟骨留下的局部能力，正式机制名为“**四声解誓**”。它能显出并摧毁塞维兰的服从铭文、解除当前宿主的强制连接、平息雾钟城共鸣，或建立仅限本地四名自愿持有者且允许撤回的地方新约。它不能重铸长誓钟、召回或命令阿瑟妲、恢复帝国疆域的完整盟约，也不能影响另外三枚钟骨。

开发约束：

- 任意可玩路线中，参与终幕的钟骨数量不得超过四。
- 照心骨可以未被玩家亲自携带，但必须明确处于封存、阵营持有或被带入初鸣庭三种状态之一。
- 玩家未进入黑砧时，照心骨只能由已建立路线的格罗姆、哈兰或托伦代取；没有对应关系与时间条件时不得凭空到场。
- “重新立约”只建立地方新约；结局不得声称完整长誓钟已经复原。
- 内部键 `fragment`、`fourth_fragment`、`witness_fragment`、`tuning_ring_repaired` 暂不重命名，避免转录数据失配；玩家界面统一显示新称谓。

称谓按知识层级变化：`truth = 0` 时角色只称“异物”“首饰里的东西”或“残片”；`truth >= 1` 时可称“钟骨”；`bone_names_known` 后才在物品栏显示旧雨骨、饥月骨、裂锤骨、照心骨。旧称并非作者用词不统一，而是玩家认知推进。

### 4.2 压力数值

```text
fragment_pressure = 1    # 0-5
fragment_used = 0        # 主动借力次数
fragment_resisted = 0    # 付出代价抵抗次数
```

- 主动借力通常提高 `fragment_used` 与 `corruption`，但不一定是邪恶；例如借旧雨骨找出被埋矿工也会伤害自身。
- 单纯点“忍住”不能无限获益。压力 3 以上时，抵抗需要 WIL 检定或消耗一个真实锚点：与同伴交谈、丢弃物品、承受疲劳、公开承认秘密。
- 当压力达到 5，下一次侵扰弹窗必须提供至少一个会破坏当前计划的冲动选项、一个高代价抵抗选项和一个将冲动转化为有用行动的选项。

## 5. 检定

公式沿用设计稿：`d20 + floor((属性-10)/2) + 情境修正 >= DC`。

| 难度 | DC | 本篇用法 |
|---|---:|---|
| 容易 | 10 | 有时间且工具合适的普通行动 |
| 中等 | 13 | 压力下的专业行动 |
| 困难 | 16 | 缺工具、受伤或对手警觉 |
| 极难 | 19 | 近乎孤注一掷；必须有失败续路 |

### 优势与劣势

- 优势：掷两次取高，不与固定 `+2` 叠加；若另有充分帮助，可再降 DC 2。
- 劣势：掷两次取低。
- 自然 20：仅在该行动可能成功时触发关键成功，不允许凭一次骰子改写世界事实。
- 自然 1：增加一个明确代价，但不应无提示杀死满血玩家。

### 失败前进

每个主线检定必须按下列顺序选取失败代价：

1. 失去时间；
2. 受到可恢复伤害或状态；
3. 提高地区警戒；
4. 损失物品、票据或关系；
5. 被迫从危险入口继续。

不得写“检定失败，什么也没发生，请重试”。

## 6. 生命、伤势与休息

- 伤害计算沿用原系统，但本篇将伤害结果写成固定范围，方便纯叙事实现。
- HP 低于 50% 获得 `wounded`：体力相关检定首次受到劣势。
- HP 低于 25% 获得 `critical`：不能选择需要全速奔跑或双手重击的选项。
- 短休耗费一个时间槽，恢复 `1d4 + CON 修正`，并触发一次残片侵扰检查。
- 长休只存在于结局后，本篇倒计时内不可用。
- HP 归零进入与当前伤害来源对应的 `10` 文件失败节点；若同伴在场且关系至少 +2，每周目仅一次可把 HP 拉回 1，同伴承受永久代价。

## 7. 携带与仓储

### 槽位

- 轻型角色 6 格，标准角色 7 格，索林 8 格。
- 穿着的护甲占 2 格但不进入背包列表；重甲占 3 格。
- 中型武器 2 格，重型武器 3 格，轻型武器 1 格。
- 三件同类小消耗品合计 1 格。
- 残片容器固定占 1 格，不能放进普通仓库；尝试丢弃会触发相应文本并在下一关键节点回到玩家附近。

### 安全点

- 白鸦旅店储物柜：需要房牌或米拉/瓦伦担保；镇区戒严后有被搜查风险。
- 红牡丹暗格：`mira_safehouse = true` 后开放，不会被帝国搜查，但米拉敌对时无法取回。
- 黑砧工棚工具箱：只存工具和武器；矿区警戒 3 时被没收。
- 商会票据：存在账面，不占格；托伦控制区兑换收 20% 手续费，瓦伦友好可免。

## 8. 私人目标

每个主角有三态：

- `unresolved`：仍能完成。
- `secured`：已经拿到可兑现成果，但终局仍可能主动放弃。
- `abandoned`：因选择或时间失去，不应在结局突然恢复。

### 艾德里克

取得一家三口的帝国离境文书或米拉伪造的商路身份。真正带家人离开还需在结局保住路线。

### 莉瑞尔

取得十年前“苔冠哨所清剿”的双重证据，并决定是否公开自己的沉默。单有证据不等于完成赎罪。

### 索林

取得交货印或证明订单被军阀劫持的账页，使家族免于违约追债。接受托伦的假印会保住钱但留下把柄。

## 9. 真相层级

| `truth` | 玩家掌握的事实 | 主要来源 |
|---:|---|---|
| 0 | 首饰中的异物会发热，并把宿主引向灰桥 | 序章必得 |
| 1 | 异物是钟骨；世界总数七枚，但雾钟城只有四枚苏醒 | 伊索尔、格罗姆、仓库账本 |
| 2 | 长誓钟是让龙与短生种跨越寿命尺度续订盟约的工具；本篇四枚只保留局部功能 | 焦页、地底壁画、凯尔证词 |
| 3 | 服从铭文由塞维兰加入；灰袍人是其残留人格；初鸣庭能执行四声解誓 | 誓环、艾琳记录、完整翻译 |
| 4 | 第七声只由知情、自愿且可撤回的承诺产生；强夺只能伪造命令或制造新容器 | 三位持有者坦白，初鸣庭照心池 |

最终的“地方新约”需要 `truth >= 4`；“四声解誓”需要 `truth >= 3` 且 `tuning_ring_repaired`；其余方案在较低真相也可执行，但结局代价可能与玩家预想不同。

## 10. 同伴规则

- 同时最多一名主要同伴进入危险节点；另一名可在安全点执行一次后援任务。
- 玩家没有选择的两位主角均可成为同伴，但不会自动同意牺牲自己的残片。
- 命令同伴做违背底线的事时，高关系只让其解释得更久，不会让其失去人格。
- 同伴死亡不是增加悲剧感的装饰。死亡后至少关闭一个终局方案、改变两个 NPC 对话并写入后日谈。

## 11. 推荐主循环

```text
显示地点正文
→ 刷新在场 NPC 与新闻
→ 玩家选择调查、交谈、整理装备或离开
→ 若离开，结算时间与旅行事件
→ 检查残片压力和共鸣阈值
→ 进入目标节点
→ 自动存档
```

重要选择前创建可命名手动存档，但不要弹出“这会改变故事”的元提示。以场景语气警告不可逆性，例如：“一旦盖下这枚印，哈兰不会再把你当平民。”

## 12. 主路径拓扑

```text
选角
├─ E-PRO-01…08 ┐
├─ L-PRO-01…09 ├─ A1-TOWN-01
└─ T-PRO-01…08 ┘

A1 城门
→ 白鸦旅店 / 礼拜堂 / 红牡丹（三选二通常最优，但可只做一处）
→ 仓库夜袭
→ 得知五种治愈方向

A2 雾钟城自由调查
├─ 白塔转移 → 可进入个人治愈结局
├─ 学院稳定 → 可进入长期治疗结局
├─ 河渠换命 → 可进入契约转移结局
├─ 西炉拆解 → 可进入内化结局
├─ 黑砧矿区（可选）→ 照心骨 / 古水道捷径 / 回城
└─ 城市支线（通常做1—2条）

获得两类定位线索或一条快速路径
→ 选择档案馆 / 白塔 / 河渠 / 无窗宅 / 古水道 / 强引入口

A3 初鸣庭：裂隙桥
→ 见证廊
→ 誓环
→ 共鸣大厅
→ 终局方案
→ END 后日谈
```

灰桥与城市支线都不是全做清单。标准周目深入三处城市地点并做一至两条支线；选择个人治愈后可以正式结束，不强迫进入初鸣庭。探索越久，诅咒阶段越高。
