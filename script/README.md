# 《雾钟城：第七声》完整文字剧本包

## 这是什么

这是《雾钟城：第七声》的第一部完整可玩剧本。它不是剧情提纲，也不是只列“这里发生一次战斗”的策划骨架；场景正文、人物台词、玩家选项、检定成功与失败文本、状态变化、回流节点、随机事件、失败结局和终局后日谈均已写明，可以直接转录为 JSON、Ink、Twine passage 或前端数据对象。

本篇从第一天傍晚开始，在次日黎明结束。玩家选择艾德里克、莉瑞尔或索林之一；未被选择的两人会作为重要 NPC 登场。三条序章在灰桥外镇汇流，随后进入可自由调查的雾钟城。玩家最初只知道自己患上会恶化的“回声病”，目标是摆脱诅咒；教会拔除、学院稳定、黑市转移、矮人内化、离城与追查城下病源都是实际可走的路线。

## 成品边界

当前 `script/` 共 24 个 Markdown 文件，约 9.3 万汉字；解析器与补丁共同生成 226 个可执行节点。内容包含城市支线、地点交互、随机侵扰、战斗、个人治愈与根源结局。统计包含开发标注与攻略，不包含用户提供的五份原始设计稿。数十万字的扩写目标仍未完成。

- 单周目目标时长：60—80 分钟；快速治愈或熟练速通约 45—55 分钟，探索型周目可超过 100 分钟。
- 一次标准流程通常阅读 18—26 个主场景、2—4 个随机事件、1—2 条城市支线、0—2 场轻量冲突并进入 1 个结局。
- 玩家可以只解决自身诅咒，也可以继续处理雾钟城共鸣；个人治愈不是假结局。世界上共有七枚钟骨，本篇只出现四枚；四枚足以完成雾钟城的“解誓”，另外三枚仅保留世界远景，不把本篇变成未完待续。
- 玩家可以救人、交易、欺骗、抢夺、投靠、逃跑或主动牺牲。邪恶路线是有完整动机和结果的玩法，不是立刻死亡的假选项。
- 不存在无代价的完美结局。最接近圆满的结果也至少失去时间、财产、身体的一部分或一段重要关系。
- 文本中的变量名与节点 ID 是开发标注，不会要求玩家直接阅读数值。

## 剧情一句话

三个只想处理各自小麻烦的普通人染上会放大记忆、欲望与愤怒的回声病；他们走进雾钟城寻找治愈，在多种真实但有代价的办法之间选择，并可能发现整座城市本身就是一台被遗忘的古代调律器。

## 关键叙事承诺

1. **小人物优先。** 每条大信息都落到具体的人：矿井坍塌意味着谁的丈夫回不来；帝国封锁意味着妹妹拿不到通行证；古代契约意味着同伴会失去一段记忆。
2. **选择改变手段与代价。** 黑砧与初鸣庭都不是强制清单；玩家可以真正在白塔、学院、河渠或西炉结束个人故事。继续追根源时，入口、同行者、伤亡和真相完整度由探索决定。
3. **失败继续产生故事。** 除 HP 归零和极少数即时死亡外，检定失败通常增加伤势、时间、敌意或债务，然后把玩家推到更糟但仍可玩的节点。
4. **残片只施压，不替玩家决定。** 冲动选项永远标注为主角自己的念头；玩家可以顺从、借力、压抑或转化它。残片不会替用户自动选择。
5. **没有无限背包。** 每件有玩法意义的物品都有槽位或负重；安全点仓储与商会票据参与剧情，不只是 UI 设定。

## 主线真相（开发者可见，玩家需逐步获得）

古龙阿瑟妲与第一帝国共同铸造的不是“让龙体验人类记忆”的装置，而是跨越寿命尺度的盟约器“长誓钟”。龙能活过数十代君王，感知山脉、水脉与百年变化，却难以判断一名短生统治者的承诺是否仍代表下一代；人类只能看见一季收成和一场战争，也无法理解开矿、筑坝在百年后对龙脉与龙卵造成的后果。双方因此需要一种不依靠永生君王、也不允许祖先替后代永久同意的翻译机制。

阿瑟妲自愿剥下一片护心鳞，帝国的人类铸钟师、精灵译誓者与矮人工匠以七道青铜誓环包裹它。长誓钟把当代签约者公开、自愿、可以撤回的承诺译成龙能感知的“第七声”；也把龙所见的百年后果压缩成短生种能够承受的梦象。每一代都必须在初鸣庭重新同意，沉默或拒绝本来同样有效。阿瑟妲参与是为了保护龙卵与地下水脉，帝国得到的则是稳定边境、灾变预警与停止误战，两方都有具体利益。

皇帝的影子顾问塞维兰不能接受新一代有权说“不”。他在誓环中加入服从铭文，伪造一个不需要同意的第七声，企图让龙、使者和后世臣民都把命令误认为自己的意愿。阿瑟妲发现后击碎长誓钟，而不是摧毁帝国；七枚钟骨散落各地，各自保留盟约的一项功能，脱离其他功能后便把记忆、欲望、拒绝或见证放大成病。

本篇只有四枚钟骨苏醒：旧雨骨、饥月骨、裂锤骨与照心骨。四枚不能重铸长誓钟、召回阿瑟妲或恢复帝国级盟约，却足以在初鸣庭完成“**四声解誓**”：显出并摧毁塞维兰的服从铭文，切断当前宿主的强制连接，平息雾钟城共鸣，或建立只约束本地四名自愿者、且任何人都可撤回的地方新约。其余三枚不在雾钟城，不是第一部收集目标。

黑砧矿脉压着照心骨，但初鸣庭藏在雾钟城第零蓄水池下。托伦开矿触动传音脉，三名主角的钟骨因此先后苏醒。四枚靠近会把记忆与情绪灌入城市水道和钟塔。灰袍人是塞维兰残存在钟骨中的一段人格，他通过“治好宿主”的承诺诱导四枚回到初鸣庭，想用不完整的四声再次伪造命令。

玩家不必知道全部真相也能解决灾难；知道得越完整，能选的方案越多，也越清楚每项方案真正牺牲了什么。

- 文中“他/她”均按当前已写角色使用，不需要运行时替换；公共场景对玩家统一用第二人称“你”。

## 验收标准

完成转录后，以下七条体验路径都必须能从选角走到后日谈：

1. 艾德里克不去黑砧，靠钟律与档案定位初鸣庭，牺牲父亲记忆切断服从铭文。
2. 艾德里克接受白塔代祷，真实痊愈并带家人离境，安瑟承担后果。
3. 莉瑞尔查清罗恩冤案、拒绝换命，与凯尔和另两名持有者重新立约。
4. 莉瑞尔欺骗罗恩完成转移后离城，诅咒不强制回到她身上。
5. 索林救矿工、取得古水道捷径、修复誓环并失去惯用手精细能力。
6. 索林保住订单后选择西炉内化，不进入初鸣庭也能获得完整个人结局。
7. 任意角色完成城市犯罪支线并夺取核心，进入支配、共治或被接管结局。

详细测试步骤见 `11_开发映射_测试矩阵.md`。
